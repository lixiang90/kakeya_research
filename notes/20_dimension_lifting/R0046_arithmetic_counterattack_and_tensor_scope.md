# R0046：固定四投影候选的算术反攻与张量范围

2026-10-17，`lifting_obstructions`。开轮读取恢复入口、R45结论及 R0046 working spec。唯一候选是下列全称有限式，不是 Kakeya 反例构造。本稿不编辑实验或元数据，不将未发现有限反例当证明。

## 1. 精确命题、删选与停止规则

对任意无挠交换群 `G`、非空有限 `Z subset G^2`，令 `M=max_x |{y:(x,y) in Z}|`，四个投影集合依次是

`S_1={x+y}, S_2={-x+y}, S_3={y}, S_4={x+3y}`。

待证或待否的式为

`|Z| <= C M^(1/3)(|S_1||S_2||S_3|)^(10/21)|S_4|^(5/21)`。 (1)

`C` 不依群、群的秩、坐标数值大小或张量次数。对 `Z` 取子集时四个集合及最大纤维数只有 upper 继承，原质量不自动继承；取 dyadic 纤维层也须记录所丢质量。若严格否定(1)，即按 spec 停止这条固定候选及本轮 seed-to-pattern 主线，不更改 `q` 或权重延长轮次；这不否定高维 Kakeya。

## 2. 任意无挠群可精确保真地压到整数

这是算术范围等价，不是新的几何输入。由 `Z` 所有坐标生成的子群 `H` 是有限生成无挠交换群，故 `H` 同构于 `Z^d`。考虑有限集合

`U=pi_x Z union pi_y Z union S_1 union S_2 union S_3 union S_4`。

取整数 `T`，定义 `ell_T(v_1,...,v_d)=v_1+T v_2+...+T^(d-1)v_d`。对于每个 `u!=v in U`，`ell_T(u-v)` 是非零整系数多项式，只有有限个整数零点。避开这些有限零点后，`ell_T` 在 `U` 上单射，并且作为群同态与四个整数系数投影交换。

令 `Z'={(ell_T(x),ell_T(y)):(x,y) in Z}`。坐标分别单射，故 `|Z'|=|Z|`，全部 `|S_j'|=|S_j|`，且每个原 `x` 纤维大小准确保持。因此：若存在任何无挠群有限反例，就存在整数 `Z' subset Z^2` 的同一基数反例；若对所有整数有限 `Z'` 有一个与数值大小无关的统一 `C`，则它已经对所有无挠群成立。

这里的 `T` 可以很大。该压缩没有方向分离、满方向网、尺度或实欧氏 angular 条件的任何结论，不能据此声称四维 finite seed 的几何入口已付。逐个有限图的精确线性保真与统一几何估计是不同责任。

## 3. 全称统一常数强迫 sharp 常数1

对固定非空 `Z` 取群 `G^n` 和笛卡尔幂 `Z^n`。四投影集合分别为 `S_j^n`；最大 `x` 纤维恰为 `M^n`，因为 upper 按坐标相乘，且选每坐标一个最大原纤维可取到该值。若(1)以同一个 `C` 对所有群成立，则

`R(Z)^n <= C`，其中 `R(Z)=|Z|/[M^(1/3)(|S_1||S_2||S_3|)^(10/21)|S_4|^(5/21)]`。

令 `n` 趋于无穷即得 `R(Z)<=1`。因此“存在统一有限 C”与“所有有限 Z 均以 C=1 成立”等价，任何一个满足

`|Z|^21 > M^7 (|S_1||S_2||S_3|)^10 |S_4|^5` (2)

的严格整数证书都足以否定全称式，而不只是排除一个预定常数。

即便将群固定为整数，也不能逃避此门槛。对整数种子先取张量，再用§2压缩到整数即可。也可显式用足够大的底数编码：`(z_0,...,z_(n-1))->sum B^i z_i`，其中 `B` 大于种子所有四投影值和坐标值的差幅的两倍加1。最高非零位支配后面位保证这些有限集合内单射，投影等式由真实整数分配律准确保持。此处没有把数字乘法或进位假设用于不合法的 Leibniz 规则。

## 4. 必要熵门槛与最大纤维的责任

一个可精确测试的必要条件是：任意有限支撑随机变量 `(X,Y)` 取值于无挠 `G^2`，若(1)成立，就必须有

`14 H(X,Y)+7 H(X) <= 10[H(X+Y)+H(-X+Y)+H(Y)]+5H(X+3Y)`。 (3)

证明先取有理概率，取长度 `n` 的联合 type class。其大小是 `exp(n H(X,Y)+O(log n))`；每个已出现的 `X` 序列有同一条件 type 的 `Y` 数目，为 `exp(n H(Y|X)+O(log n))`；每个投影序列都在其相应固定 marginal type class 内，故投影集合大小至多 `exp(n H(projection)+O(log n))`。在 `G^n` 中代(1)，除以 `n` 后取极限，得 `21H(X,Y)<=7H(Y|X)+10 sum H_j+5H_4`，即(3)。实概率由有限支撑上的熵连续性得到。

这是必要条件；没有在本稿中声称其反方向或完整 entropy-to-cardinality equivalence。不能把任意一个均匀 `Z` 的 `log M` 免费换成 `H(Y|X)`：只有上面的联合 type 施工支付了各纤维控制。对均匀 `Z` 单独使用 `H(Y|X)<=log M` 不足以得更强的(3)。

## 5. 已检验的符号模式与容易漏掉的纤维

变元 `a=x+y,b=-x+y` 将四投影写成 `a,b,(a+b)/2,2a+b`，而 `x=(a-b)/2`。在整数例中取同奇偶的 `a,b` 即可；作为无挠群中的计数讨论，只使用乘2单射，不假设任意群元素可除2。最大纤维正是 `a-b` 的最大重数，不能以 `a,b` 的笛卡尔自由度代替。

满二维矩形和单投影核方向的伸缩没有立即否定(1)。例如在 `G=Z^2` 取 `x=(u,v),y=(u,0)`，`u in U,v in V`，所有 `x` 互异，所以 `M=1`。精确得到 `|Z|=|U||V|`、投影基数 `( |U||V|,|V|,|U|,|U||V| )`，(1)右边为 `(|U||V|)^(25/21)`，不构成反例。即使在有限域2里 `2u=0` 可改变第一个基数，在无挠群中这一消失不成立，不能搬用该模型。

所有“某一个投影恰为单点”的情形可直接排除为反例：其余三个投影和 `x` 在 `Z` 上均单射，因为不同投影系数的行列式是非零整数，而群无挠。因此 `M=1`、其余三个基数均为 `N=|Z|`。若单点是 `S_4`，右边为 `N^(10/7)`；若是前三者之一，则为 `N^(25/21)`，均不小于 `N`。这不处理厚ened 核邻域或多个纤维的组合。

另一准确的两参数图为 `x=u+2v,y=u`，`u,v in {0,1}`。其 `x` 唯一，故 `M=1`；四投影大小为 `(3,2,2,4)`，点数4。整数证书左边 `4^21=2^42`，右边 `12^10 4^5=3^10 2^30`，后者更大。此类小数字模式的笛卡尔幂保留同一个比率，不会由“多层重复”反转失败方向。

还可完整核一个任意长度图族，而不只列有限样本：

`Z_m={(2k-1,1),(2k,0):0<=k<m}`，`m>=1`。

其最大纤维是1，四投影大小为 `(m,m+1,2,m+1)`，`|Z_m|=2m`。证书左右之比准确是 `2^11 m^11/(m+1)^15`。在正实数上取对数求导得唯一最大点 `m=11/4`，最大值为 `2^19 11^11/15^15<1`；分子分母整数分别为149585485161299968和437893890380859375。因此整个图族及其全部笛卡尔幂均不反驳候选。`m=3` 的比值为 `177147/524288`，正是 root 搜索所报六点图的一种平移。这只是排除这一个有明确式子的模式，不是从有限搜索推出所有图的结论。

这些只是精确校准，不代表已穷尽低维图、非均匀 law 或不等大 `S_j`。实际有限枚举和输出由 root 独立归档；本稿不把有限搜索未命中写成全称验证。

## 6. 当前结论与几何桥的边界

到本稿当前步骤，尚无严格无挠有限反例，也未证明(1)。已付的是可核验的范围收缩：任意群反例可压成整数；全称常数必须 sharp1；(2)是精确可扩大的整数失败证书；(3)是具有完整 type/fibre 预算的必要 entropy test。

root 已完成十个明列16点网格全部655350个带标签非空子集的精确整数比较，另一个 bitmask/等值类算法重算；未发现反例，402457个样本在 `N>M^2` 域。本代理实读两程序与完整输出，并独立只读核 SHA256、十个 adjugate 网格、十个所报最优见证的原计数和合计；没有将有限范围称为全称验证。重复网格可能重复同一个集合，这个总数不是不同集合数。

对四维 finite seed 的实际桥，A/root 已逐式核自然直线 `(t,F(y)+tF(x))`：四个集合只控制四时标，不满足原 long marks；加厚的 drift cover 没有新 saving，补自由角的直接产品因子相消。仍须支付方向 bin cap/分离、同一 clock、逐管或平均 shading 的正确闭包及所有常数。尤其把整数点拉长到分离各个编码值，可能同时使方向集中和 `delta` 极细；不能一边取 all-G tensor 去损失，一边把 tensor 后的维数、坐标条件数或独立 clocks 忽略。本轮没有合法的新桥，按一轮规则停止这份 seed-to-pattern 施工；(1)本身保持未证未否，不以“算术等式保真”当作新几何进展。
