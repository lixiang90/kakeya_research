# R0116 后继入口：原逐管密度能否供 AP 超饱和

## 为什么先检这个输入

Dahia v1 的 Lemma 1.2 先消费一个已构造的稀小通用整数 AP 模型，再用固定密度 Varnavides 找 rich translate。它没有提供 Euclidean 原单位管的模型，也没有支付密度降到 δ^η 的常数。选择审查结论是 prototype-cover 资格为零；不启动“先假设小模型或低编码 cover，再做计数”的主研究。

下一项可证伪测试只问：其 AP 预处理在原逐管 near-full 密度门是否存在。经典无进位球层很可能已否定无条件版本，故只准一次有上限的准入核算，不把已知 AP-free 方法包装为新路线或重大结果。检验后必须转向真正使用方向与空间重叠的联合输入，不能沿 mask 常数或 AP 长度续轮。

## 原对象、量词与待攻击命题

固定 a∈(0,1) 和容差 C≥0。对任意足小 η>0、所有足小 dyadic δ，令原 T 是 R^5 内全方向 δ-net 的真实单位线段 δ 邻域，N≈δ^−4；方向按无向单位方向计。每个 T 的可测 marks Y(T)⊂T 均满足 |Y(T)|≥δ^η|T|。原 I=Σ_T|Y(T)|，λ=I/(Σ_T|T|)，不先删方向或改 N。

测试的最低结论是：至少一根原管的轴向单位 arclength clock 集合中，有 τ_0,τ_1,τ_2，满足

    |τ_0+τ_2−2τ_1| ≤ Cδ,
    min(τ_1−τ_0, τ_2−τ_1) ≥ δ^a.

若连存在性都失败，则任何在这些假设下统一声称正幂数量、可返回原 I 的 3AP 超饱和也失败。这个命题没有 small-footprint、joint AD 或完整 source 假设；其反例不能否定附有那些额外几何信息的命题。

## 独立攻击配方及必须逐项支付的账

审查建议用等平方范数的整数球层 A⊂{0,…,m−1}^d，在 base 2m 中编码。若 x+z=2y，数字加倍无进位；同球层严格凸性将迫 x=z。抽屉大小预计 ≥c_d n^(1−2/d)，n=(2m)^d。先独立核这些精确整数断言，不能以有限样本替代全参数证明。

为同时处理 Cδ 容差与 dyadic 尺度，必须在 clock 格之间留固定大间隔 Lδ，取 L 大于 C 加上区间厚度所付误差；不能只厚化成 cδ 后声称所有 C 的近似 AP 都消失。m、L 可取二的幂，固定 d 后选择 dyadic 子序列。把格放在单位轴内固定内区间，每格厚化 cδ，并保留原垂直 δ 截面。证明任何所列近似 AP 的中心格仍满足精确整数 AP，重复格又不能供 δ^a 间隔。

独立核原 tube 的端帽体积、可测性、单位长度、全部方向与原 N；取 2/d<η、尺度足小后，含常数的逐管密度才可真正超过 δ^η。不能仅报 δ^(2/d+o(1)) 而省去量词。逐管成立应直接给平均 λ，不能由平均倒推每管。原 I 由实际 marks 体积计算。

若实施此配方，它只是 full-footprint 压力模型，不是低维 Kakeya 构造。若要加入 small footprint 或完整 source，必须另写并实际验证全套假设；不得在本测试中把它们补成“显然”。

## 删选闭包、旧失败与停止条件

先查 R0114 whole-cell mask 与 R0115 full-source graft：本次只核 AP 预处理，不能将它们当作新一般 cover 定理。预先固定有限实体族的编码预算已有选择审查；按 marks 自适应、高复杂度族不受该简单反攻，亦未自动获得正输入。

AP-free 性对 marks 删选保留，但密度会变；保 p 比例原 I、q 比例原管时 λ′=(p/q)λ，仅到常数体积比较。平均和逐管密度门分别验。若候选仅在 power-small-footprint 反设下成立，应先查旧全称 finite 排除在所有合法删选上重调用是否已推出它，不能用新名称回避双向蕴含审查。不得预认证两者等价。
