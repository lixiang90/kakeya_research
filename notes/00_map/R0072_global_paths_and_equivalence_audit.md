## 2. 先支付 restriction 与两种 shading 闭包

原 label 族上删 whole labels 保留下来每根原管的逐管 density；只在 shading 上另作删选则必须重新计算每根密度。平均密度 lambda 可先 heavy：删 density<lambda/2 的 labels 损至多原总 incidence 一半，但剩 label 数只保证约 lambda 倍，不能仍称保原管数常数比例。若随后按窗口、carrier、angle 或 point 取最大组，应按实际 incidence 选组，并把该分组的重数和分母留在式中。

AD upper、absolute CW/PW upper 可传至子族但其原归一化质量不能免费重设；AD lower 一般不传。原 Φ_p 条件角 law 不自动等于全局末角 law，同一点出发的 arm 在不同终点得到的 Φ 也不能强写为同一 physical packet。ξ 的原 coherence 只是在同物理粗格内比较，并不提供一个整 grain 上相同的 ξ 或其像的 lower dimension。

common parent/window 还须保共同 clock、whole straight axis 和真实 rounding 误差。R49 的预算说明“已经找到保原质量 parent/window 后如何支付”，不证明这种 parent 或 joint AD 初始化必然存在。短 clock/crop 的归一化常数必须与原质量一起计算，不能独立取新 K 为 subpower。

## 3. 必须拒绝的等价与冻结指纹

1. **CP/PM**：对全部合法原 shading/restrictions 统一的正幂 CP 可重调用推出 PM，反向亦然。再命名 joint entropy、inverse 或 endpoint completion 不产生新的输入。
2. **原 W/action/BSG**：R18/R27–28 已保真实增量和共同 box，但没有可迭代 action closure；抹掉 g 独立化、把同一次加法能量换成增长仍是同一未付责任。R45 fixed-arm BL 也不能只补一个 good-rank 名称，固定 endpoint 字母表的主幂并未改。
3. **PW4/projective direction recovery**：R62 在 named 四维有限输入下付 U4 whole union、S4 nearfull shading、P4 adaptive whole-axis 有界射影门槛的正幂双向等价。因此“挑好远超平面/富 pencil 恢复方向”若没有新固定格式质量估计，是完整 PW4 困难的改名。
4. **R58/R64/R65**：standalone secant law 的二维 Frostman 化、raw rank 分类或光滑/有理 Jacobian 截断均不能代替原 A-output。R65 真正排的是额外有理曲率类，并不为任意 dyadic-Lip f 提供 regularity。
5. **R69–71**：固定四个输出值后两 simple poles 可非 AFF；条件 κ packet 的 fibre/frame 损失已完整计算。current lower certificate 不够，不等于 actual output ratio 必坏，但没有新 source 输入就不能续参数。

这些判断是排重边界，不是对所有可能高维方法的不可能性定理。

## 4. direction-energy / projective-parent 的筛查

R61 的精确变换方向为 q_a=(1+a·p)v−(a·v)p。固定 map 或固定 universal 列表失败不能反 adaptive gate；同样，joint3-Frostman upper 或一个 pair second moment 不是恢复全部三维方向帽的证明。坏 map 对许多 pairs 可高度相关，不能从平均碰撞误称存在保原 incidence 的统一好图。

原 direction Frostman 的共同 affine/restriction 成本与 PW 的 parent 成本在 R42 已比较；R43 又付实际 coarse PW 闭包。提出“新 parent energy”必须说明新增的是哪一项原质量控制，不能重新假 all-scale direction regularity 或把 arbitrary many-bin union 当 fixed-format PW 测试。一般 N 管 union 格式随 N 增长，原 PW 不免费给 whole union 大体积。

本次本地检索没有找到一个已存在但尚未调用、能直接跨过该门槛的 direction-energy 输入；A 负责官方版本和一手新输入核对。本稿不以无命中认证不存在或新颖性。当前建议不选此路线作没有新估计的 R72 phase II。

## 5. common-kernel 商 gate：这是 R58–59 的旧门槛

设实际 d5、k=ell=3 中 f(z)=F0+u(z)e^T，u 为任意允许的二维 dyadic-Lip 曲线。共同 bounded shear/水平 rotation 后可写 F0=0、e=e1，原 grain 为

    (x1,x2,y+u(z)x1,z)，y∈Y_z。

删 x2 保原直线与 clock；但 ξ_p 可依 x2。原 CW 对 projected r-bin 的 bounded kernel 凸棱柱查询给 projected probability≤K^C r^3。原 joint4-AD lower 再给每 occupied projected r-bin 的 lifted r-bins **至多** K^C/r。这是 upper，不是所需的 typical fibre **至少** K^−C/r，不能推出商 support≤K^C r^−3 或商 joint3-AD lower。

原 projected marked footprint 的 N_delta 上界为 K^C delta^(−4+kappa)。这个空间上界并不迫商 line-parameter entropy 为3。filled x2 是空间点占据，而不同 ξ(x2) 可以产生不同商支持线。固定投影的 φ1 law 也不自动 κ-AD；二维 Φ 的 κ-AD/slab 允许其某标量投影仅具有较小指数。scalar projection of Y 可满一维，故不能只投影两次套13.5。

R16 PENCIL/IMAGE 排除不覆盖一般 common-kernel u；转置矩阵不是原点/线/shading 的 ambient 映射，graph 的正交补也不自动产生一个合法的 dual source。R59 已明确没有正 kappa 全 source counter，但旧 gate 没有付 basicness 和商 lower。root 已同意不以相同 quotient 问题作为 phase II。

## 6. 可供锁题的不同变量：沿核坐标的原 normal velocity 响应

一个比直接索求商3AD更具体的待测变量，是同一原管在两个终时的 Y-normal 响应。以原 source 符号，在 common-kernel 下，原 native 标签为

    y_s=y+(s−t) ξ_y(x2)+[u(t)−u(s)](x1+(s−t)φ1)+O(delta)。

只有固定初始 (y,x1,t)，定义 yhat_s=y_s−[u(t)−u(s)]x1 后，才可写成 y+(s−t)ξ_y(x2)+(s−t)[u(t)−u(s)]φ1+O(delta)；不是跨 root 的共同坐标替换。

这是候选筛查用的结构式；所有 proxy/δ 误差、条件点集合、实际可用 two-time incidence 和恢复尺度仍须 phase II 在 spec 中先锁定后完整核。对 Δu(t,s) 垂直的法向投影会严格消去 φ1 项，因此可能检验 ξ_y 沿 filled x2 的 non-basic 部分；但下面的反攻不可绕过：

- dense X 与 dyadic-Lip coherence 不给 ξ 像的任何一维 lower，也不保证两终时保留同一组原管/同一 conditional angle law；两次平均不能冒同一 joint law。
- ξ 的变化若沿 Δu，单个投影会丢掉它；标量 Y 投影可以 full1，单次 rank/Jacobian 或 image 计数至多提示 1+gamma，而 Y 容量是2−kappa。小 gamma 区域不能因此闭合。
- 若需要两个不同 Δu 的方向，它们的间隔、同一 filled kernel fibre、同一原 ξ 和对应 whole-tube visits 必须由原质量共同支付，不能增添 good-rank、smooth derivative、独立 Markov/BSG 或 free conditional AD。
- 可攻击“dense domain+Lip response 自动一维 image”的有限校准，但它若不保 full T/AD4/CW、whole clock、Φ 与 Y，须明确只反这一步，绝不是 source/Kakeya 反例。

推荐只把它作为一个此前未量化的 **原核坐标响应步骤** 候选：先证明真实 two-time 联合质量/重数/恢复式，再检查是否获得足以支付 R59 fibre-lower 的 basicness，或直接由原 Y tube-KT 排除 non-basic 分支。若最后仍只要求 desired quotient lower、generic inverse theorem 或旧 high-kappa 子范围，就拒绝重开，不登记新 ID。

## 7. 阶段 I 结论和 phase II 停止线

阶段 I 结论是：普通初始化、ordinary 多尺度、完整 matrix/mixed 和真实构造四条路径均仍有明确原量词缺口；R59–71 的 proper 类与合法接口没有解决它们。直接 common-kernel quotient、PW4 的射影重述及 R71 packet 不宜重开。当前唯一可交 root 决定的不同变量是上一节的原 kernel-coordinate ξ 响应，**尚无已证新输入，也未声称它足以完成 whole matrix 分支**。
