## 3. 可以精确算出的旧后果

写F(x)表示一个由旧种子和旧KT得到的下界函数。其意思始终是：对每个固定x及任意目标余量ε>0，可得到K(x,F(x)−ε)的实际finite版本；不是一个统一endpoint线性损失模量。初始F0(x)=4，x≥4。Th6.2的旧critical关系是

    4d = 2x+1+F(d+1).                            (1)

若第二参数所在区间已有F(y)=ay+b，则(1)的根是

    d = [2x+1+a+b]/(4−a).                        (2)

这个根能用有限次合法KT调用逼近：从已有较低d开始，每次用严格次临界第一输入及第二输入，所得d向根递增；给定最终余量只需有限次数，再取所有源门槛的最小值。实际取参数略低于各根和断点，最后用目标余量吸收，不需要在δ内无限迭代。所用第二参数是d+1，保持≥4，任意ambient的真实unsaturated输入由FSD和KT(40)提供。

得到的前几段为

| 实参数范围 | 旧闭包可得F(x) |
| --- | --- |
| 4≤x≤11/2 | 4 |
| 11/2≤x≤13/2 | x/2+5/4 |
| 13/2≤x≤33/4 | 4x/7+11/14 |
| 33/4≤x≤45/4 | 7x/12+11/16 |
| 45/4≤x≤131/8 | 24x/41+109/164 |

例如第二段先用常数种子4；第三段把第二段代入(1)，由(4−1/2)d=2x+11/4得d=(8x+11)/14。第三段内d+1确在[11/2,13/2]。下一段同理由(4−4/7)d=2x+33/14得到7x/12+11/16。断点由d+1等于上一段右端点确定，并非把实参数n误当整数ambient。

对任何更大固定x，也可继续这一旧代数：令a0=0、b0=4，

    a_(k+1)=2/(4−a_k),
    b_(k+1)=(1+a_k+b_k)/(4−a_k).

从第一正斜率区间左端p1=11/2开始，下一右断点满足

    p_(k+1)=(p_k−1−b_k)/a_k,  k≥1.

这给出每个固定x的一段有限表达，不声称穷尽结合所有其它文献输入后的最优下界。a_k趋于2−√2，b_k趋于4√2−5；因此这次恒定4种子的旧闭包也没有改变经典KT的渐近线性斜率。

按R38§20，integer n的相应任意Euclidean Kakeya集合有dim_H≥F(n)。只列用于排重的数值：

| n | F(n)的精确值 | 十进制近似 |
| --- | --- | --- |
| 6 | 17/4 | 4.25 |
| 7 | 67/14 | 4.785714 |
| 8 | 75/14 | 5.357143 |
| 9 | 95/16 | 5.9375 |
| 10 | 313/48 | 6.520833 |
| 11 | 341/48 | 7.104167 |
| 12 | 1261/164 | 7.689024 |

这些是符号代入，不是新有限计算实验。n7旧闭包甚至低于库存GLX/HRZ明确普通基线34/7；没有在本稿新查当前前沿，更不根据其余数字认证改进、首次或最佳。单次只用d=d′=4−ζ给(2n+5)/4，不能冒充上述再调用的全部可得强度；反过来，补完更强旧算术也不能充新数学机制。

## 4. 旧指纹与双向蕴含

这一候选完全落入R81《one_fullrank_geometry_and_old_fingerprint_gate》§8、R85§4/§7、R88§4及R107§10明确冻结的critical-resolvent/上包络重算。KT原文Th6.2之后已经公开迭代所有实参数的affine family。源种子、适用参数域、ambient责任、原质量预算均未新增。当前用户授权续研没有自动撤销这些防循环约束。

蕴含方向必须准确：全部旧finite种子加具名KT推出§3全部finite后果；因此它不增加该输入体系的数学假设。反向若把候选写成**所有x≥4、所有固定ambient、所有合法finite原shadings**上的K(x,F(x)−ε)族，因为F(x)≥4，向下弱化即恢复全部K(x,4−ζ)种子。在固定KT可调用的理论里，它只是旧种子族的闭包整理。若只陈述某单个n的Hausdorff数字，反向不推出任意ambient finite种子，不能声两种类型的声明等价；这不改变其正向完全由旧输入给出的事实。

对于另起名的cover/low-multiplicity/entropy候选，R15仍是具体筛查：平均原选择类若对whole-output-cell删选封闭，CP(σ)统一对全部选择成立，就可在只保高重数cells后再调用，得到每τ<σ的常数比例低重数质量PM(τ)；PM又除重数阈值推出CP。只有单个实例的cover数值不够，但全称shading量词足够。该论证不能无核地换成逐管nearfull类，因为whole-cell删选可能使许多原管无marks。本稿没有发现一个避开该旧闭包且已具原质量证明的新估计。

## 5. restriction与shading闭包：平均、逐管分别核

设原管数m、原incidence数I、平均密度λ=δI/m。只保q比例的whole labels并再删marks，最终保原I的p比例，则

    m′=qm, I′=pI, λ′=(p/q)λ.                    (3)

绝对计数角帽upper对子族继承；把方向law归一成概率时，其upper常数须除q。KT同参数饱和条数要求q是可支付的subpower比例；固定δ^c损失不能忽略。只知道q不够保平均密度，所选标签可能全是原light tubes；必须实核p或逐管duration。

**平均类。** 只要I′≥λ′m′δ^-1达到已选η门槛，可heavy提取至少cλ′m′条、每条至少cλ′δ^-1个自己的旧marks。FSD旧式给

    #E′ ≥ c (λ′)^2 m′ K^-1 δ^(s−4+ε)/log(1/δ).

故两次λ费用都在，不能说平均先heavy免费变为原全部逐管近满。按(3)重写密度与条数的因子是p²λ²m/q，不可只保管数后沿用原λ。固定幂duration是否允许，须与事先选定η比较，不能事后把它统称o(1)。

**逐管类。** 原来每管各自≥λδ^-1个marks时，保whole labels及其所有marks确实保逐管density；若每管另保至少r比例旧marks，density改为rλ。仅保p比例总incidences不给每管r，whole-cell删选也不保这一性质。先heavy后可以再选择合法子族，但管数分母、角law常数和原marks必须重新计费。逐管已知时避免某些heavy损失是旧闭包；在nearfull KT入口没有新的空间主幂。

共同clock/charts、fixed多次mesh着色、任意条数第二输入和δ0顺序沿FSD原证明，不把不同管的marks拼到同一新管；把M或调用次数随δ无界增长都超出这里已付的闭包。

## 6. 独立反攻、完整路线与可执行目标判定

对§3的压力测试是：一律只保单个n的seed而去掉全实参数族，(1)的d+1就可能无来源；把ambient固定成物理R4，KT新R^(M+1)输入就失配；令标签或duration损固定δ幂，必须重新计(3)；把小于根的有限次调用改成统一endpoint模量则超出量词。上述均已在旧实际输入里正确限定，没有由它们产生一个新缺口或反例。

完整ordinary/HRZ仍须付真实footprint、direction、shape/cap、parent与λ/尺度。R85/R88/R107已经说明，四维finite输入或三维全λ最大函数的标题本身不补这些账。完整rough的终端ξ恒等式已见原(148)、W路径与R75，R108的n4计数图严格拒绝由全终端碰撞CS自动给同初kernel-fibre的非对角lower；不能以“再多几个time/holonomy”重开。R106两锚族未满足nativeY tubeKT，R107又有未由wholeF非拟合导出的横向law；不能将其附加假设删掉当增益。旧toy均不提供同一个全方向strict Hausdorff反例。
