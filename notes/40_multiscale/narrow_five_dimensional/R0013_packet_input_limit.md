# R0013：四平面包的可用输入与planebrush数值极限

2026-10-17，root。对象为真实R5管及原cubical shading，不恢复旧formal completion。以下局部包估计条件于完整四维证明及DIR-003；模板算术另有明确假设，不将尚未核完的Kulkarni算法当成已验证输入。

## 1. 同一原packet的有限密度估计

设一组方向δ-separated的单位δ管T_j全部位于固定仿射四平面H的Cδ邻域内。Y_j(T)为原whole-cube shading，每管至少λ/δ个时标，λ≥δ^θ，θ相对所需ε足够小。则在条件性四维输入DIR-003下，

    |E_j| ≥ cε δ^(4+ε) λ #T_j, E_j=∪_T Y_j(T).       (P1)

理由逐项如下。因为整根管在H的Cδ邻域，方向的法向分量Oδ，轴线投影长度与1可比。一个投影δ方向bin只能有O_C(1)个原δ-separated方向，故常数着色后投影仍方向分离。有限个graph时间charts与常数重分箱保留原时标，各管的不同访问时标在投影后只有常数重数。

以每根索引权1调用DIR-003：投影方向bin质量α=O(1)，long marks比例λ，得到投影四维cell数至少δ^ε λ #T_j/δ。故

    |π_H E_j| ≥ cε δ^(3+ε) λ #T_j.                    (P2)

这里DIR003中mark移至time-bin中心产生的固定Oδ扩大，不造成额外幂成本：每个投影whole cube都含半径cδ的四维球且直径≤Cδ，故该投影并的固定倍δ邻域体积至多其体积的固定倍。用δ-separated covering中心的球打包即可证明；因而expanded cell count可转回原|π_HE_j|。

对任何whole δ-cubes的并E_j，都有|π_H E_j|≤Cδ⁻¹|E_j|：每个cube的投影4-volume≤Cδ⁴，原5-volume=δ⁵，投影并体积不超过和。这不假设fibres逐点填满，也不以投影满维免费加一。(P1)随即成立。

这里未在包内重新正规化概率，不新增shading标签，不用任意密度的4D maximal theorem。DIR-003本身条件于SRC-001及**完整**四维证明和输入正确；只有Hausdorff主定理陈述不足以调用它。

## 2. 仅把包输入理想化不能超过维数四

设一只合法根刷能提取N个原管，且已有实际计数

    N ≥ c λ³ ρ δ⁻¹ |U|⁻²,                            (P3)

又能分成上述四平面包，剩余shading保逐管λ密度，并有足以求和的有界重叠。则(P1)仅推出

    |U| ≥ cε δ^(4+ε) λ N,
    |U|³ ≥ cε δ^(3+ε) λ⁴ ρ.                          (P4)

即使ρ、λ都是subpower，这只有|U|≥δ^(1+o(1))。η可按ε变小只能消掉损失，不能把δ¹改成δ^(1−σ)。这不是(NG)不成立，而是明确说明这个计数加包输入的模板没有所需增益。

(P3)、原包密度保持和全刷分解在此都是假设，没有借thesis打印算法免费获得。其完整声明/打印待补证处见R0013_primary_narrow_audit.md。即使以后修复算法，(P4)的指数障碍仍在。

## 3. 包体积因子本身不能有统一负幂改善

取H≅R4中的一个固定3维方向patch，δ-net共≈δ⁻³条轴线从H内同一点发出。它们是实际R5单位δ管，ambient方向δ-separated，全marks，且全在H的Cδ邻域内。所有管的total5-volume≈δ⁻³δ⁴=δ，union5-volume≤Cδ，因为它们在一个固定有界四平面的δ厚邻域内。

所以不能把对所有包适用的(P1)改成|E_j|≥cδ^(4−σ) #T_j（λ1、σ>0）。它将迫该真实包union≥cδ^(1−σ)，与≤Cδ矛盾。该包只有δ⁻³方向，不是主(NG)的满δ⁻⁴族；它只校准了包级估计的最大可能强度。新gain必须来自跨包关系、更多刷路径或真正的新几何，而非把4D输入换成更强的同种packet lower。

## 4. 三轴刷闭合与两轴的自由度

一个精确的局部事实说明额外rank需要在哪里：设P为R5的仿射3-plane，y∉P，三条过y的直线与P相交，且方向线性独立。若它们方向都属于一个3维子空间W，则相交点在P∩(y+W)内且仿射不共线，故该交至少为2-plane。P∩(y+W)又不能是3-plane（否则y∈P），所以恰为2-plane。于是y+W内任何不平行该2-plane的线都与P相交。

只有两条刷轴时结论不成立。取P=span(e₁,e₂,e₃)，y=e₅，W=span(e₁−e₅,e₂−e₅,e₄)。前两方向的轴分别交P于e₁,e₂，第三条y+R e₄则完全不交P。W仍是一个合法3-plane。

这个span事实没有提供三轴事件的质量，更没有给δ近似情形的uniform成本。原方向分离和两步刷计数不能直接当成三轴richness；三轴退化、中间角宽、沿线平面变化的质量都须从真实incidences证明。另一代理的满方向旋转平面场构造进一步排除了沿同一管自动平面一致的捷径。未证明(NG)，也未给其反例。
