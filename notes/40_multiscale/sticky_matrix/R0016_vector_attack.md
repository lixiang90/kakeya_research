# R0016：逐方向差落直线分支的联合图排除

2026-10-17，lifting_obstructions。当前主缺口为完整五维 sticky Mat(2,2) 非线性配置；不是任意矩阵函数的和积问题。本稿严格证明一个有限联合图分支：若每个固定 Φ 差上的矩阵作用曲线落一条仿射直线，则原 Y 的 tube Katz–Tao、Φ 的 slab Frostman、矩阵非仿射与 dense translation graph 不能同时成立。结论依赖源文标量 Theorem13.5；不声称独立重证该输入，不证明完整 N5-STICKY-MATRIX-01，不给 Kakeya 反例或新维数界。

完整 source 配置、参数顺序及停止条件见 R0016 working_spec。此前 CP/PM 等价路线保持冻结。本稿只编辑本文件，不向一般管族添加原配置假设。

## 1. 来源与真正可用的标量输入

Wang–Zakharov arXiv2609.22035v1 PDF88–89页的(165)来自原 L-tuples：在归一化尺度 r，平移为

    a + (b−b′)(F(b)−F(b′))(φ₁−φ₂).                 (1.1)

承载集合是同一个二维 Y 的局部输入、输出；平移所作用的参数是原 Φ 差，不是 Y 自身。因此 He Theorem3 的 Y+Y、Y+AY 小增长输入不能直接替换(1.1)。He–de Saxcé Theorem2.3 还要求每个 Jordan–Hölder 商上的非集中、稳定子逃逸及载体远离子模；此处尚未导出这些输入。

本稿只调用 WZ Theorem13.5 的 β=1、乘数集合 C={1} 特例：若标量函数 H 在所有仿射函数附近均不集中，且 dense triples 使 a+(b−b′)(H(b)−H(b′)) 的输出 covering 不超过输入大小的一个小幂损失，则标量输入 A 的 r-covering 至少 r^(−α)，任意固定 α<1。其非线性精度指数必须足够小，依赖1−α；不能把任意固定精度指数的版本当成已证。

本分支利用 Y 的 tube Katz–Tao 在每条细条带内给 α<1 的 upper，不要求 Y 的某个标量投影具有小维数，也不假定最大 fiber 承载足够原质量。

## 2. 严格有限命题及参数

固定 γ_T、γ_Φ∈(0,1] 和 b₀>0。存在 a₀(γ_T)>0，使以下结论对0<a<a₀(γ_T)成立。先固定

    b = min(b₀/20, a γ_Φ/100, 1/100),

再取 h>0 足够小，依赖全部先前参数及 Theorem13.5 的阈值；最后取 r>0 足够小，可依赖 h。所有集合位于固定有界盒内，固定倍常数只影响 r₀。设：

1. B⊂[−1,1] 为非空 r-separated (r,1,r⁻ʰ)-set；具体用到每个长度 s≥r 的区间含至多 r⁻ʰ s #B 个点。
2. 有限原差标签空间 Λ 带概率先验 ν，每个标签 s 有向量 ψ_s∈R²，向量有固定上界。其差向量 law 满足 line-cap：每个宽 t≥r 的有界 slab 含至多 r⁻ʰ t^(γ_Φ) 的 ν 质量。保留标签重数，不能只取 distinct ψ 后改用 uniform counting。
3. A₋、A₊⊂R² 为非空 r-separated 集合，#A₊≤r⁻ʰ#A₋。A₋满足(r,1−γ_T,r⁻ʰ)-tube Katz–Tao。特别在任意固定倍 r 宽、长度有界的条带内，A₋的点数至多 C r^(−1+γ_T−h)。不要求 A₋、A₊为乘积或纤维 AD。
4. F:B→Mat(2,2) 有固定范数上界。对所有实矩阵 R,U，

       #{b∈B: ||F(b)−bR−U||∞≤r^a} ≤ r^(b₀)#B.     (SM_r)

5. 有原联合图权重0≤g(a,b,b′,s)≤1，对标签用 ν 积分，其总权至少 r^h#A₋(#B)²。每个正权 tuple 的 a+(b−b′)(F(b)−F(b′))ψ_s 距 A₊至多 C r。
6. 对每个被图用到的差标签 s，曲线 {F(b)ψ_s:b∈B} 包含于某条仿射直线 L_s；允许退化为一点，直线可随 s 改变。

则上述六项不能同时成立。使用0≤g≤1只用于把原质量与最大可选 tuples 数比较；若来源尚是有大重数的 L-tuples，必须先核原 multiplicity 上界及合法归一化，不能免费宣称权重有界。原(165)已写成图集合时可直接取 indicator 权重。

若确有一个 slab-Frostman Φ且 ν 为其 uniform有序差 law，则条件2由固定 φ₂、对 φ₁计 slab 后积分直接得到。更一般地，同一 p 内原 Φ_p×Φ_p 差 law 的加权混合也继承该 cap，只要每个原 law 的常数统一。这里优先采用 ν 形式，避免从“Φ_p 包含于粗 Φ_q 的邻域”错误推出全部粗 Φ_q cells 都 slab-Frostman；额外未用 cells 可以集中。

该命题不需要 Φ 的 κ-AD 或 A 的(2−κ)-AD；完整 source 数据当然还包含它们。这里只用了其中确实足够的部分，不把删去的条件从主目标中删除。将 L-tuple 差 marginal 接到上述原 ν，仍须核 multiplicity 支配，不能只用一个没有来源的优良 ν 替换。

## 3. 固定方向差后的合法 fiber 质量分配

记 d_s 为 g 对 A₋×B×B 的平均。令 P 为 d_s≥r^h/2 的差标签。总质量与 g≤1 给

    ν(P) ≥ r^h/2 ≥ r^(2h).                         (3.1)

对固定 s∈P，取 L_ψ 的单位切向量 v；若曲线常值，先记下它在全部 B 上已经仿射，以下无需对该 s 使用标量定理。否则写

    F(b)ψ = c_ψ + v H_ψ(b),

其中 c_ψ 可取一个曲线点，H_ψ 有固定上界。常数项在差中抵消，平移严格沿 v。

沿 v⊥把 A₋分到宽 r 的半开条带，输入条带点集为 A_k。令 A_k⁺包含 A₊中垂直坐标距该条带≤C r 的点。有限相邻条带保证

    Σ_k #A_k⁺ ≤ C′#A₊ ≤ C′r⁻ʰ#A₋.               (3.2)

这里 C′只依赖原 O(r) 误差常数。删去 #A_k⁺>r^(−5h)#A_k 的条带；其输入总点数至多 C′r^(4h)#A₋，故所能承载的原 g 质量至多 C′r^(4h)#A₋(#B)²。这小于该 s 的原质量一半。因而在未删条带中，存在某个 k 满足

    Σ_{a∈A_k,b,b′}g ≥ r^(3h)#A_k(#B)²,
    #A_k⁺ ≤ r^(−5h)#A_k.                         (3.3)

每个 s 可以得到不同条带；没有挑最大 fiber、没有改成按 fiber 重新归一化后再假定 dense。损失从同一个原 g 的总质量直接支付。

将 A_k 沿 v 投影并按 r-grid 取代表。条带宽 r、原 r-separation 使每个标量 grid cell 的原点重数有固定上界，所以得到标量输入 D_s，#D_s≈#A_k；图的原权经这一映射至多损固定因子。其 exact scalar translated outputs 距 A_k⁺的投影 O(r)，从而

    scalar graph density ≥ r^(4h),
    N_r(output) ≤ r^(−6h)#D_s.                   (3.4)

固定倍坐标缩放/取整只改变 O(r) 误差和固定倍尺度，可用额外 h 余量吸收。tube Katz–Tao 同时给

    #D_s ≤ C r^(−1+γ_T−h).                       (3.5)

这一步使用的是 A₋自身的条带 upper；仅知道输出 A₊的 cardinal 比较，不能替代输入的 tube Katz–Tao。

## 4. 每个 good 差上的标量仿射拟合

取 α=1−γ_T/2、β=1，使用 Theorem13.5 的乘数指数0、ε₁=4a、ε₂=b。a₀先选到使4a在该定理允许范围；再让20h小于其两个 η 阈值且 h<γ_T/10。

若 H_ψ 对所有标量仿射函数在 r^(3a) 误差下命中至多 r^b#B 个点，则固定倍归一化到[−1,1]后，其 r^(4a) 误差条件仍成立。原 B 的非集中、(3.4)的 density 与 output upper 足够应用 Theorem13.5，得

    #D_s ≥ c r^(−1+γ_T/2),

与(3.5)矛盾。故每个 s∈P 均有向量 coefficients r_s,u_s∈R²，以及 B_s⊂B，使

    #B_s > r^b#B,
    ||F(b)ψ−b r_s−u_s||∞ ≤ C r^(3a),  b∈B_s.     (4.1)

常值曲线直接取 B_s=B，也满足。这里没有声称 B_s 相同、没有把它们正规化后再假定 source AD；下一步只用原 B 上的真实交集计数。

## 5. 两个独立差在同一批时间上重构矩阵

由 ν 的 line-cap，ν{s:|ψ_s|<r^(4h/γ_Φ)} ≤ C r^(3h)。删去这些标签只损 P 的小部分；重记剩余集合为 P，仍保(3.1)，稍微缩小 r 即可吸常数。

令

    d = 10b/γ_Φ ≤ a/10.

对一个剩余 ψ₁，用另一个差向量满足 |det(ψ₁,ψ₂)|<r^d 所对应的 strip 计量：该 strip 宽至多 C r^(d−4h/γ_Φ)。因此坏标签对的 ν×ν 质量至多

    C r^(10b−5h).                                (5.1)

所用 strip 宽在[r,1]内：h≪b且 d≤a/10<1。另一方面，Cauchy–Schwarz 对(4.1)的原 B_s incidence 给

    ∫_{P×P}#(B_s₁∩B_s₂) dν(s₁)dν(s₂)
        ≥ r^(2b)ν(P)²#B
        ≥ r^(2b+4h)#B.                           (5.2)

坏对的交集至多#B，故 h≪b 使(5.1)所能贡献的小于(5.2)的一半。于是存在一对 s₁,s₂，其差矩阵 Ψ=(ψ₁,ψ₂) 满足

    |det Ψ|≥r^d,
    #(B_s₁∩B_s₂)≥(1/2)r^(2b)#B≥r^(3b)#B.        (5.3)

将两列(4.1)合并，记 R′=(r_s₁,r_s₂)、U′=(u_s₁,u_s₂)。在这个同一时间交集上

    ||F(b)Ψ−bR′−U′||∞≤C r^(3a).

Ψ的 entries 有固定上界，故 ||Ψ⁻¹||≤C r⁻ᵈ。右乘得对所有这些 b，

    ||F(b)−bR′Ψ⁻¹−U′Ψ⁻¹||∞
        ≤ C r^(3a−d) ≤ r^a.                    (5.4)

3b<b₀，故(5.3)的命中数严格超过(SM_r)的 r^(b₀)#B，矛盾。逆矩阵可以产生很大的仿射 coefficients；SM_r允许所有实 R,U正是这里需要的量词。整个两差选择保留 ν×ν 原权，没有把不同 p 的原 Φ 相互独立拼接成一个未经证明的 uniform粗网。

## 6. 覆盖的实际可约机制与稳定性

这不是只展示一个可约矩阵例子。命题排除了一个完整 graph branch，包括：

- F(b)=F₀+v r(b)，固定像方向 v、任意1×2行曲线 r(b)。
- F(b)=F₀+h(b)M，任意固定2×2矩阵 M；M可以满秩，尤其包括标量矩阵 pencil。此时固定 ψ 后的像沿 Mψ，方向可随 ψ 改变。

不需把 M 的最小奇异值倒过来，也不需假设 ||Mψ||有统一下界。若 Mψ=0，该差已在全部时间上仿射；其余差使用单位输出方向和有界的实际 F(b)ψ 即可。

更一般地，每条 F(B)ψ 仅距相应仿射直线 O(r) 也可用同一证明：平移误差仍 O(r)，(4.1)再加 O(r)，最后的逆矩阵误差≤C r^(1−d)，在 a₀<1/12 时仍小于 r^a。这里只给 O(r) 稳定邻域，不把更粗的 anisotropic near-rank 条件无证明并入。

这排除的是包含 SM、两类非集中及原 dense graph 的共存，不是声称这些 slope functions 本身不存在。它们也不是满足完整 source 配置的反例。

## 7. 与实际源尺度的接口及明确边界

原源尺度记ρ，最终图分辨率 r≈ρ；归一化 F=(f(z)−f(z″))/(τ/ρ)，τ≈δ^(-Oη)ρ²。保原 fine/coarse 权重的工作由本轮 tuple audit 及 root 接口稿负责。本稿没有直接把原 z 网格当成ρ-separated B：原 b=(z−z″)/ρ的最细间距是δ/ρ，其 cardinal一般大于ρ⁻¹，必须合法粗化。

all-real SM的粗化也要证明，不能只说 F Lipschitz 就忽略拟合 slope。一个可用的必要步骤是：若某仿射矩阵 fit 命中至少 r^c#B 个 r-separated times，#B≥r^(−1+o(1))，则这些命中点的 span≥r^(c+o(1))，bounded F 迫 ||R||≤C r^(−c−o(1))。故 time rounding引入至多 r^(1−c−o(1))误差；若1−c大于拟合精度指数，才能把同一 fit 转回 fine time points。单个 bin 内的任意大 slope 无需排除，但不得用它满足大命中数门槛。

在完整源接口确实给出 r^h损失、相对 SM精度 r^a 与质量 r^(b₀)时，本命题立即适用。可取 a为固定倍 ε₀，b₀为固定份额源ε，先明确选 ε₀足够小依赖γ，再 ε≪ε₀γ，最后 η足够小使 O(η/μ)损失小于 h。没有缩小原固定 κ。若接口只保一个 scalar projection 或不同 prior，本稿不能调用。

一般 Mat(2,2) 曲线可能对足够多 ψ 产生真正二维的 F(B)ψ；本证明没有处理该情形，也不从“矩阵不在一条 pencil”推出定量不可约或 He 的作用闭包。因此完整 N5-STICKY-MATRIX-01仍未解决。下一步必须获得该剩余分支的实际联合质量/扩张输入；不能以 scalar投影满维、子代数分类或改写目标登记为完成。本轮结果仅为依赖既有标量定理、可独立审查的严格分支排除。
