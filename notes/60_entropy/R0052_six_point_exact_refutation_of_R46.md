# R0052：六点有理 law 严格否定 R46 固定加权候选

2026-10-17，root。结论针对旧算术候选，不是欧氏 Kakeya 反例或高维新界。完整独立审查记录另存；未经外部同行评审，不作新颖性或重大结果声明。

## 1. 原命题、量词和本次证明范围

R46 要求对每个无挠交换群 G 及每个非空有限 Z⊂G² 有与群、坐标数值及集合无关的 C，使

    N ≤ C M^(1/3) (S1 S2 S3)^(10/21) S4^(5/21),        (R)

其中 N=|Z|，M=max_x|Z_x|，S1、S2、S3、S4 分别是 x+y、−x+y、y、x+3y 的不同值数。本稿构造 M=1 的有限整数图族，使左/右无 C 比值无界。因此即使固定 G=Z，(R) 也不成立。

R51 的新一手报告触发本轮检查，但本证书独立构造；没有复现报告中 SD≥1.668 的概率表。六点 law 只需较弱的特定加权熵差。原 R46 的 655350 个带标签均匀小网格未发现反例仍为正确的有限历史记录，不能排除这里的非均匀 type 构造。

## 3. 不含浮点的严格加权熵差

对整数边际权 c_v，H=log Q−Q^−1∑c_v log c_v，记 P=∏c_v^(c_v)。令

    Δ=21H(D)−10[H(A)+H(B)+H(A+B)]−5H(A+2B).

由权重总数可逐项推出

    exp(QΔ)=(P_A P_B P_AB)^10 P_A2B^5 /
             [Q^(14Q) P_D^21]
           =5^100/(2^140 3^54)>1.

最后一步是纯整数比较，root 与 A 独算，A 另用有理 atanh 展开和正尾上界给自然对数的严格有向区间。数值 Δ≈0.381510198 只供阅读，不是证明输入。本 law 对 A+2B 的强测试 3H(D)>5H(A+2B) 反而失败：对应整数比为 2^40/3^42<1。因此它不是 SDfour>5/3、更不是 1.668 的复现。

## 4. 一个明确有限 type 集合，长度 240

令 k=20、n=12k=240，取全部行字 w∈{1,…,6}^n，其中六种行出现次数依次为 20,40,60,60,40,20。逐坐标用该行的 A、B 定义向量 a(w),b(w)∈Z^n，再置

    x(w)=b(w)−a(w),  y(w)=a(w)+b(w),  Z_n={(x(w),y(w))}.

D 在六行上单射，故 x(w) 唯一决定每个行字，N=|Z_n|=n!/(20!40!60!60!40!20!)，并且 M=1。这里不需删代表；一般非单射 D 的逐目标 type 选择论证见 B 稿，本实例已直接支付目标 type 满射。

四投影向量恰为 2b、2a、a+b、2(a+2b)。它们分别包含于 B、A、AB、A2B 的边际 type 类，基数上界记 K_B、K_A、K_AB、K_A2B，分别以边际次数的多项式系数 n!/∏(kc_v)! 计算。**不把这些 upper 擅自当作实际投影的精确基数。**

纯整数阶乘比较给

    N^21 > (K_A K_B K_AB)^10 K_A2B^5.                 (F)

left 的 bit length 为 12011，right 为 11971；真实整数、输入/程序 hash 与差值 hash 存在 root 输出，A 从 joint 表另外计算。于是实际 Z_n 严格违反 C=1 的 (R)。无需枚举天文数量的行字，也无需仅凭渐近 Stirling 忽略有限误差。

## 5. 同时整数编码确实保最大纤维及所有投影

每一坐标的 x、y 及四形式的绝对值均≤6。对任何长度 m 定义 ℓ(v)=∑_{j=0}^{m−1}v_j14^j。若两个坐标字不同，最高不同位的贡献绝对值≥14^h，其余位总差≤12(14^h−1)/13<14^h，故 ℓ 在这些字的并上单射。

ℓ 为整数加法同态，与四形式交换。所以把 Z_n 映到 {(ℓ(x),ℓ(y))}⊂Z² 精确保 N、M=1 以及四投影的全部等值关系和基数。负 digit 不产生漏洞，上述差值证明不要求正 digit。此压缩没有几何角度或尺度条件数保证，不能据此生成欧氏 Kakeya 构造。

## 6. 张量排除任意统一常数

记实际投影积相应表达的比值 r=N/[(S1 S2 S3)^(10/21) S4^(5/21)]。由 (F) 和 upper 有 r>1。对 Z_n 取 t 次 Cartesian product，每个 N、Sj 恰取 t 次幂，M 仍为 1；并在长度 nt 使用同一个 base14 编码压回 Z²，所有基数保持。

若 (R) 对整数集合有固定有限 C，则全部 t 要求 r^t≤C，与 r>1 矛盾。这一步才排除原统一 C；单次 C1 反例或单次熵计算本身不足代替它。量词允许整数坐标随 t 增长，正好属于原命题范围。
