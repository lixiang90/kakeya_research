Besicovitch set
Definition
A set B ⊂ Rn is a Besicovitch set if it contains a unit line segment in
every direction.
Theorem (Besicovitch 1917)
In Rn (n ≥ 2) there exist Besicovitch sets of Lebesgue measure zero.

Kakeya conjecture
Definition
A set is a Besicovitch set if it contains a unit line segment in every
direction.
Kakeya Conjecture
In Rn every Besicovitch set has Hausdorff dimension n.
Theorem (Davies 1971)
The Kakeya conjecture holds for n = 2.
Theorem (Zahl-Wang 2025)
The Kakeya conjecture holds for n = 3.
The Kakeya conjecture is open for every n > 3.

=== PDF PAGE 5 ===
Variants
Definition
B is a Besicovitch set if it contains a unit segment in every direction.
Kakeya Conjecture
In Rn every Besicovitch set B has Hausdorff dimension n.
The Kakeya conjecture is often stated only for compact or Borel B.
Often, instead of line segments, we want full lines in every
direction.
One can also require unit line segments only in a set of directions
of positive n − 1-dimensional Lebesgue measure or
n − 1-dimensional Hausdorff dimension.
It was widely belived that all of these variants are equivalent.
We proved with András Máthé that this is indeed the case: all of these
forms of the Kakeya conjecture are equivalent.

Statement about the equivalence
Theorem (K-Máthé 2022)
For every n there exists a real d ≤ n with the following properties:
1 There exists a compact Besicovitch set of Hausdorff dimension d.
2 There exists a closed set of Hausdorff dimension d that contains a
line in every direction.
3 If S ⊂ Rn contains a line segment in a set of directions of
Hausdorff-dimension n − 1 then dimH S ≥ d.
Therefore for all possible combinations of variants we considered there
exists a set of minimal dimension, and this minimal dimension is
always the same for any fixed n.

Are lines much bigger than line segments?
Line Segment Extension Conjecture (K, 2015)
If A is the union of line segments in Rn and B is the union of the
corresponding full lines, then dimH A = dim H B.
Theorem (K, 2015)
This conjecture for n would imply that for any Besicovitch set
B ⊂ Rn we have dimH B ≥ n − 1.
If this conjecture holds for every n ≥ 2 then any Besicovitch set
has upper Minkowski dimension n.
Theorem (K, 2015)
The Line Segment Extension Conjecture holds if dimH A < 2 or
dimH B ≤ 2. In particular the conjecture holds in the plane.

General Kakeya Conjecture
Héra, K, Máthé (2018): The union of any s-dimensional family of
lines in Rn has Hausdorff dimension s + 1 if s ≤ 1.
We proved with András Máthé that the following general statement is
also equivalent to the Kakeya conjecture:
General Kakeya Conjecture
Let E be an aritrary subset of Rn and let D be the set of directions in
which E contains a line segment. If D ̸= ∅ then
dimH E ≥ dimH D + 1.
Remarks.
The above result implies that this conjecture holds if dimH D ≤ 1.
A possible way of improvement could be to prove it for dimH D ≤ t
for some t > 1.
A possible way to disprove the Kakeya Conjecture is to disprove
this more general but still equivalent conjecture.

Typical Besicovitch sets
Theorem (T. Körner 2003)
A Besicovitch set, which is typical in the Baire category sense must
have Lebesgue measure zero.
That is, in a suitable defined complete metric space the set of those
Besicovitch sets that have positive Lebesgue measure is meager.
To prove the eqivalences of the several versions of the Kakeya
conjecture we also used a similar approach with András Máthé
although our setup was a bit different. In particular we showed the
following:
Theorem (K-Máthé 2023)
In any Rn a typical Besicovitch set has minimal Hausdorff dimension.
That is, if d is the minimal possible Hausdorff dimension of a
Besicovitch set in Rn then in a suitable defined complete metric space
the set of those Besicovitch sets that have Hausdorff dimension d is
residual / co-meager.

Results about typical Besicovith line sets
Theorem (K-Máthé 2023)
For any n there is a real d such that in Rn
d is the minimal Hausdorff dimension of Besicovitch sets (no
matter which variant we consider) and
a typical Besicovitch line set has Hausdorff dimension d.
Therefore, in order to solve the Kakeya problem, it is enough to find the
Hausdorff dimension of a typical Besicovitch line set.
Now our goal is to show that if a typical Besicovitch set in Rn has
Hausdorff dimension less than n − 1 then it must have weird
disjointness properties, which seem to be impossible.
If these properties are indeed impossible that would imply that any
Besicovitch set has Hausdorff dimenson at least n − 1.

A disjointness property of typical Besicovitch line sets
Lemma
If B ⊂ Rn is a fixed compact set such that its projection to every
n − 1-dimensional subspace has empty interior (in particular, if
dimH B < n − 1) then a typical Besicovitch line set in Rn is disjoint to B.
"Proof". We show that the (code sets of the) good collections of lines
form a dense open set in K.
By compactness, if S(K ) and B are disjoint then S(K ′) and B are also
disjoint whenever K ′ is close enough to K in the Hausdorff metric. This
shows that the (code sets of the) good collections form an open set in
K.
Since the projection of B to any n − 1-dimensional subspaces H is a
compact nowhere dense set, most lines that are perpendicular to H
are disjoint to B. With some extra work this gives the denseness.

More disjointness properties
Lemma
If B ⊂ Rn is a fixed compact set such that its projection to every
n − 1-dimensional subspace has empty interior (in particular, if
dimH B < n − 1) then a typical Besicovitch line set in Rn is disjoint to B.
We get immediately the following:
Corollary
If a typical Besicovitch line set in Rn has Hausdorff dimension less
than n − 1 then countably many typical Besicovitch line sets are
pairwise disjoint.
We also get:
Corollary
If a typical Besicovitch line set in Rn has Hausdorff dimension less
than n − 1 then a typical Besicovitch line set consists of pairwise
disjoint lines.

Combined main result
Corollary (combined)
If a typical Besicovitch line set in Rn has Hausdorff dimension less
than n − 1 then
countably many typical Besicovitch line sets are pairwise disjoint,
a typical Besicovitch line set consists of pairwise disjoint lines.
Since typical Besicovitch line sets has minimal Hausdorff dimension
among Besicovitch sets and they are formed by compact collection of
line sets, we obtain the following:
Theorem (Combined main result)
In Rn if there exists a Besicovitch set of Hausdorff dimension < n − 1
then there exist compact collections C1, C2, . . . of line sets such that
each Ci contains lines in every directions,
all the lines of ∪i Ci are pairwise disjoint.

Questions about possible constructions
Theorem (Combined main result)
In Rn if there exists a Besicovitch set of Hausdorff dimension < n − 1
then there exist compact collections C1, C2, . . . of line sets such that
each Ci contains lines in every directions,
all the lines of ∪i Ci are pairwise disjoint.
So the natural goal is to prove that such collections cannot exist. We
do not even know if there exists one such collection.
Questions
1 Is there a compact collection of pairwise disjoint lines in Rn such
that we have lines in every direction?
2 If yes then how many such collections can one give so that their
unios are pairwise disjoint?

Weaker constructions
Questions
1 Is there a compact collection of pairwise disjoint lines in Rn such
that we have lines in every direction?
2 If yes then how many such collections can one give so that their
unios are pairwise disjoint?
What if we relax the compactness assumption?
If we simply delete the word "compact" in the above questions
then by transfinite induction it is easy to construct even infinitely
many such collections.
If we require any kind of measurability (instead of compactness)
then the questions are already highly nontrivial. In this direction
the best we could achieve is the following.
Theorem
There exist a closed collection of pairwise disjoint lines in R3 such that
we have lines in every direction.

Constructions in R3
Theorem
There exist a closed collection of pairwise disjoint lines in R3 such that
we have lines in every direction.
Instead of proving this theorem we first show how we can get slightly
weaker results.
Using hyperboloids of one sheet we can get a closed collection of lines
in R3 such that we get lines every non-horizontal directions.
In fact, similar constructions also work in Rn for any odd n > 3 but we
do not have constructions in even dimensions.
