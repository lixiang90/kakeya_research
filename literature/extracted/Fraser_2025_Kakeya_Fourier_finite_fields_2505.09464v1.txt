Fourier analytic properties of Kakeya sets in finite fields
Jonathan M. Fraser
University of St Andrews, Scotland
email: jmf32@st-andrews.ac.uk
Abstract. We prove that a Kakeya set in a vector space over a finite field of size q
always supports a probability measure whose Fourier transform is bounded by q−1 for
all non-zero frequencies. We show that this bound is sharp in all dimensions at least
2. In particular, this provides a new and self-contained proof that a Kakeya set in
dimension 2 has size at least q2/2 (which is asymptotically sharp). We also establish
analogous results for sets containing k-planes in a given set of orientations.

1. Introduction
1.1. Kakeya sets in finite fields. A Kakeya set in Rd is a set which contains a unit line
segment in every possible direction. The Kakeya conjecture is that such sets must have
Hausdorff dimension d. This is despite the fact that they can have zero d-dimensional
Lebesgue measure for d ⩾ 2; a result of Besicovitch [Be28]. Davies solved the planar
(d = 2) case [Da71] and the d = 3 case was recently resolved in a breakthrough paper of
Wang and Zahl [WZ25+]. The problem is open for d ⩾ 4.
Oberlin proved that Kakeya sets in R2 have Fourier dimension 2, that is, Kakeya sets
in R2 are Salem sets [Ob06]. Oberlin’s result implies (and is rather stronger than) Davies’
result that such Kakeya sets have Hausdorff dimension 2. We generalised Oberlin’s ar-
gument in [FHK22] to prove that the Fourier dimension of a Kakeya set in Rd is at least

To the best of our knowledge the finite field analogue of Oberlin’s result is unknown.
We prove it here and in the process give a new proof of the asymptotically sharp lower

Theorem A. If K ⊆ F2

A natural generalisation of a Kakeya set is a ( d, k)-set, which is a set in d-dimensional
space which contains a k-plane in every orientation. There has been a lot of work on
these sets in the Euclidean setting, but we only discuss the finite fields setting here, see
[EOT10, KLSS11]. We consider a slight generalisation of ( d, k)-sets where we only require
a given subset of possible orientations. Write G(d, k) for the set of all k-dimensional
subspaces of Fd
q and let Γ ⊆ G(d, k). We say K ⊆ Fd
q is a (d, k, Γ)-set if for all V ∈ Γ, there
exists u ∈ Fd
q such that u + V ⊆ K. In particular, K is a ( d, 1, G(d, 1))-set if and only if
it is a Kakeya set. We first obtain Fourier analytic estimates for ( d, k, Γ)-sets in Theorem
2.1 before specialising to ( d, k)-sets in Corollary 2.2 and then Kakeya sets in Proposition
2.3, Theorem 2.4, and Corollary 2.5.
1.2. Notation. Throughout the paper we write A ≲ B to mean there is a constant c
independent of q for which A ⩽ cB. Similarly we write A ≳ B to mean B ≲ A and A ≈ B
if A ≲ B and A ≳ B. One should always think of q as being very large compared to any
implicit constants. We also write |E| to denote the cardinality of a set E and A ∼ B to
mean that A/B → 1 as q → ∞.

The conclusion that ( d, k)-sets asymptotically take up the whole space when k > d/ 2 is
a finite field analogue of a result of Falconer in the Euclidean setting [Fa80], which states
that ( d, k)-sets in Rd must have positive Lebesgue measure when k > d/ 2. In the finite
fields setting, the cardinality estimate in Corollary 2.2 is known, and in fact much stronger
estimates are available. Therefore, the main novelty of Corollary 2.2 is in the Fourier
analytic information, but we do offer a new proof of the optimal asymptotic cardinality
estimate in the case k > d/ 2. In fact, for all k ⩾ 2, it is known that ( d, k)-sets in Fd
q have
cardinality ∼ qd, see [EOT10, KLSS11].
We now focus on the case k = 1, that is, the setting of Kakeya sets. We first prove that
the estimates above are sharp in all ambient dimensions d ⩾ 2.
Proposition 2.3. For all d ⩾ 2, κ ∈ (0, 1), and sufficiently large q, there exists a Kakeya
set K ⊆ Fd
