                                                                                 1. Introduction
                                             Let G(k, n) be the set of m-dimensional subspaces in Rn . For V ∈ G(k, n), define
                                          πV : Rn → V to be the orthogonal projection onto V . Throughout the paper, we
                                          use dim X to denote the Hausdorff dimension of the set X.
                                             There is a classical result proved by Marstrand [11], who showed that if A is a
                                          Borel set in R2 , then the projection of A onto almost every line through the origin
                                          has Hausdorff dimension min{1, dim A}. This was generalized to higher dimensions
                                          by Mattila [12], who showed that if A is a Borel set in Rn , then the projection of A
                                          onto almost every k-dimensional plane through the origin has Hausdorff dimension
                                          min{k, dim A}.
                                             There is a finer question known as the exceptional set estimate. It is formulated
                                          as follows. Fix integers 1 ≤ k < n. For a, s satisfying 0 < s < min{k, a}, find
                                          (1)       T (a, s) :=         sup       dim({V ∈ G(k, n) : dim(πV (A)) < s}).
                                                                  A⊂Rn dimA=a

                                          To avoid the measurability issue, we assume the set A is Borel throughout the
                                          paper. We remark that T (a, s) also depends on another two parameters k, n, but
                                          since k, n are fixed, we just drop them from the notation for simplicity.

the exceptional set. Roughly speaking, the exceptional set is the set of directions

Of course, we trivially have T (a, s) ≤ dim(G(k, n)) = k(n − k). Here are some
nontrivial results on the upper bound of T (a, s).
      (i) T (a, s) ≤ k(n − k) + s − k.
     (ii) T (a, s) ≤ max{k(n − k) + s − a, 0}.
    (iii) T (a, nk a) ≤ k(n − k) − 1.
The estimate (i) was first proved by Kaufman in R2 (see [9]), and proved by Mattila
in higher dimensions (see [12]). For the the estimate (ii), it was originally obtained
by Falconer (see [3]) in a slightly different formulation. Peres-Schlag also proved the
result (see [16]). The estimate (iii) was obtained by He (see [8]). We remark that

n = 2, k = 1.

one of the result, we can improve (iii).

Example 29. Let N be a large number. We assume 2s ≥ a. Consider a set of
