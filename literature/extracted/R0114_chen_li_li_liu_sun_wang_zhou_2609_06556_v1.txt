                                                                                1. Introduction

                                             The Kakeya problem is one of the most popular math problems recently. A set in Rd
                                          is called a Kakeya set (also called a Besicovitch set), if it contains a unit line segment in
                                          every direction. In 1928, Besicovitch [1] constructed Kakeya sets of Lebesgue measure
                                          zero. We also refer to [4][9] for classical constructions and [8][5] for recent constructions.
                                            Though a Kakeya set may have Lebesgue measure zero, it is still expected to be
                                          “large”. The famous Kakeya conjecture states that the Hausdorff dimension of every
                                          Kakeya set in Rd must be d. It has been solved in the plane by Davies [3] (see [11] for
                                          other proofs), and in R3 by Wang-Zahl [10] recently.
                                            In a very recent work, Fraser and Yang [6] studied restricted Kakeya sets, which
                                          are Kakeya sets with the additional restriction that centers of the unit line segments
                                          belong to a given set A ⊂ Rd . By applying Bourgain’s bush argument [2], they are able
                                          to obtain better estimates on dimension of restricted Kakeya sets when A has smaller
                                          dimension.
                                             Inspired by the work of Fraser-Yang and the raising of the Kakeya conjecture, we are
                                          wondering if a restricted Kakeya set can have Lebesgue measure zero, especially when
                                          A is small. While a countable set A is clearly insufficient, we show that the countability
                                          is in fact the only obstruction.
                                          Theorem 1.1. Suppose A ⊂ Rd , d ⩾ 2 is an uncountable Borel set. Then there exists a
                                          compact subset of Rd of Lebesgue measure zero that contains, in every direction, a unit
                                          line segment whose center lies in A.

  In this section, we collect several standard definitions and fundamental results from
geometric measure theory and point-set topology that will be used throughout the
paper.

  For each t ∈ R, we define the projection mapping πt : R2 → R by
                                     πt (b, a) := bt + a,
and for the vertical direction, let π∞ (b, a) := b. Note that πt (b, a) coincides with the

projection theorem for irregular sets is stated as follows:
Theorem 2.2 (see, e.g. [4, Theorem 6.13]). Let E ⊂ R2 be an irregular 1-set. Then
the projection πt (E) has 1-dimensional Lebesgue measure zero for almost every t ∈ R.

2.2. Perfect sets. A subset A ⊂ Rd is called a perfect set if it is closed and contains
no isolated points.
Lemma 2.3 (Alexandrov–Hausdorff, see, e.g. Theorem 13.6 in [7]). Every uncountable
Borel set in Rd contains a compact subset homeomorphic to the ternary Cantor set, i.e.,
a non-empty, bounded, totally disconnected perfect set.

   Every perfect set is uncountable. In fact, if A is perfect and x ∈ A, then every
neighborhood of x contains uncountably many points in A, for otherwise, if A = {xi },
then one can construct a decreasing sequence of closed balls {Bi } with Bi ∩ A ̸= ∅ and
xi ∈
   / Bi . So Lemma 2.3 has the following corollary.
Corollary 2.4. Let A ⊂ Rn be a perfect set. If U is a non-empty relatively open subset
of A, then U contains a non-empty perfect subset.
