                                                                                             Abstract
                                                      A Kakeya set is a compact subset of Rn that contains a unit line segment pointing in every
                                                  direction. The Kakeya conjecture asserts that such sets must have Hausdorff and Minkowski
                                                  dimension n. There is a special class of Kakeya sets, called sticky Kakeya sets. Sticky Kakeya
                                                  sets exhibit an approximate multi-scale self-similarity, and sets of this type played an important
                                                  role in Katz, Laba, and Tao’s groundbreaking 1999 work on the Kakeya problem. We propose a
                                                  special case of the Kakeya conjecture, which asserts that sticky Kakeya sets must have Hausdorff
                                                  and Minkowski dimension n. We prove this conjecture in three dimensions.


                                          1       Introduction
                                          A compact set K ⊂ Rn is called a Kakeya set if it contains a unit line segment pointing in every

                                          The Kakeya set conjecture and Kakeya maximal conjecture were proved for n = 2 by Davies [10]
                                          and Cordoba [9], respectively. The conjectures remain open in three and higher dimensions.
                                               The Kakeya conjecture is closely related to questions in Fourier analysis. This connection was
                                          first explored by Fefferman [17], who used a variant of Besicovitch’s construction to show that the
                                          ball multiplier Tcf = χB fˆ is unbounded on Lp (R2 ) when p ̸= 2. In [3], Bourgain obtained new

                                          point in different directions, and estimates of the form (1.1) can be used to analyze the possible
                                          intersection patterns of these wave packets.

    Since Bourgain’s seminal work [3], Kakeya estimates have served as an input when studying
the Fourier restriction problem [7, 11, 44], and methods that were developed in the context of the
Kakeya problem have been successfully applied to the Fourier restriction problem, Bochner-Riesz
problem, and related questions. Indeed, the modern renaissance in polynomial method techniques
was sparked by Zeev Dvir’s proof [13] of Wolff’s finite field Kakeya conjecture. These polynomial
method techniques have since revolutionized discrete math, combinatorial geometry, and harmonic
analysis. See e.g. [23, 39] for a modern survey of these developments.
    In this paper we will restrict our attention to the Kakeya set conjecture in three dimensions.
In [46], Wolff proved that every Kakeya set in R3 has Hausdorff dimension at least 5/2. In [25],
Katz, Laba, and Tao made the following improvement: every Kakeya set in R3 has upper Minkowski
dimension at least 5/2+c, where c > 0 is a small absolute constant. Katz, Laba, and Tao’s argument
began by carefully analyzing the structure of a (hypothetical) Kakeya set that had dimension exactly
5/2. At scale δ, such a set K would contain a union of roughly δ −2 1 × δ tubes that point in δ-
separated directions, and the union of these tubes would have volume roughly δ 1/2 . Next, Katz,
Laba, and Tao considered how these 1 × δ tubes would arrange themselves at scale ρ = δ 1/2 . Since
the 1 × δ tubes point in different directions, each 1 × ρ tube can contain at most ρ2 /δ 2 1 × δ tubes.
If equality (or near equality) holds (i.e. if the 1 × δ tubes arrange themselves into roughly ρ−2 many
1 × ρ tubes, each of which contain ρ2 /δ 2 1 × δ tubes) then we say the arrangement of 1 × δ tubes is
sticky at scale ρ. As a starting point for their arguments in [25], Katz, Laba, and Tao used a result
by Wolff [48] to prove that that if a Kakeya set K has upper Minkowski dimension 5/2, then the
corresponding set of 1 × δ tubes must be sticky at every scale ρ ∈ (δ, 1).
    Motivated by this observation, we introduce a special class of Kakeya sets, which we call sticky
Kakeya sets. Let L be the set of (affine) lines in Rn , equipped with the metric d(l, l′ ) = |p − p′ | +
∠(u, u′ ). Here u (resp u′ ) is a unit vector parallel to ℓ and p (resp. p′ ) is the unique point on ℓ
with p ⊥ u. Since the direction map from L to RPn−1 is Lipschitz, if L ⊂ L contains a line in every
direction then dimP (L) ≥ n − 1. (Here dimP denotes packing dimension; similar statements hold
for other metric notions of dimension, but this is less relevant to the current discussion). We say a
Kakeya set is sticky if equality holds:
Definition 1.1. A compact set K ⊂ Rn is called a sticky Kakeya set if there is a set of lines L with
packing dimension n − 1 that contains at least one line in each direction, so that ℓ ∩ K contains a
unit interval for each ℓ ∈ L.
    Observe that if we drop the requirement that L has packing dimension n − 1, then we have
recovered the usual definition of a Kakeya set. In particular, every sticky Kakeya set is also a
(classical) Kakeya set. As we will see in Section 2, when sticky Kakeya sets (in the sense of
Definition 1.1) are discretized at a small scale δ > 0, the corresponding collection of 1 × δ tubes
is sticky in the sense of Katz, Laba, and Tao. With these definitions, we can introduce the sticky
Kakeya set conjecture.
Conjecture 1.1. Every sticky Kakeya set in Rn has Hausdorff and Minkowski dimension n.
     A defining feature of sticky Kakeya sets is that if K is a (hypothetical) counter-example to the
sticky Kakeya conjecture, then K must be roughly self-similar at many different scales. This was
first observed in [25] and discussed in greater detail in [43]. A precise version of this principle is
stated in Proposition 3.2 below.
     Since every sticky Kakeya set is also a (classical) Kakeya set, the Kakeya set conjecture implies
the sticky Kakeya conjecture, and partial progress toward the Kakeya set conjecture implies the
same partial progress for the sticky Kakeya conjecture. In particular, Davies’ solution [10] to the
Kakeya set conjecture in the plane implies that Conjecture 1.1 holds when n = 2. In this paper,
we will prove Conjecture 1.1 for n = 3.

Theorem 1.1. Every sticky Kakeya set in R3 has Hausdorff dimension 3.
    Our proof of Theorem 1.1 is inspired by, and partially follows, the arguments recorded in Terence
Tao’s blog entry [43]. That blog entry sketches an approach to solving the Kakeya conjecture in
R3 that was explored by Nets Katz and Terence Tao in the early 2000s. In brief, [43] begins by
conjecturing that a (hypothetical) counter-example K ⊂ R3 to the Kakeya conjecture in R3 must
be sticky, and must also have two additional structural properties, which are called planiness and
graininess. We will discuss this conjecture in Section 1.2 below. Next, the blog entry describes how
these three properties can be used to obtain multi-scale structural information about K. Finally,
the blog entry suggests how to use this structural information to produce a counter-example to
Bourgain’s discretized sum-product theorem [4], and hence obtain a contradiction.

1.1   A sketch of the proof
We will briefly outline our approach to proving Theorem 1.1, and discuss how it relates to Katz
and Tao’s strategy, as described in [43]. Katz and Tao’s strategy was influenced by the following
example from [25], which is called the (second) Heisenberg group example:

                            H = {(z1 , z2 , z3 ) ∈ C3 : Im(z3 ) = Im(z1 z̄2 )}.                   (1.2)

The set H is a counter-example to a strong form of the Kakeya conjecture. In particular, the
δ-neighbourhood of H ∩ B(0, 1) contains about δ −4 “complex unit line segments,” and at most δ −2
of these line segments are contained in the δ-neighbourhood of a (complex) plane in C3 . This set
has (complex analogues of) the structural properties stickiness, planiness, and graininess, but it
has volume substantially smaller than 1. At a key step in our argument, we will use (a consequence
of) Bourgain’s discretized sum-product theorem to distinguish between a sticky Kakeya set in R3
and the Heisenberg group example.
    Our proof can be divided into three major steps. The first step follows some of the arguments
described in [43]. For steps 2 and 3 our arguments take a different path from those presented in
[43]; we do this in part because sticky Kakeya sets can have structural properties that were not
discussed in [43].
Step 1: Discretization and multi-scale self-similarity
In Section 2, we set up a discretization of the sticky Kakeya problem that allows us to exploit
multi-scale self-similarity. The technical details of this procedure are new; in particular, we explain
how to replace each 1 × δ tube by a reasonably large subset (called a shading), so that key statistics
of the Kakeya set are maintained after successive refinements. We hope that this setup will be
useful when studying the sticky Kakeya conjecture in higher dimensions.
    In Section 3, we flesh-out the ideas from [43] to obtain multi-scale structural information about
sticky Kakeya sets. The main conclusion of this section is as follows. Suppose that the sticky
Kakeya conjecture in Rn was false, i.e. inf dimH K = n − σn , where the infimum is taken over all
sticky Kakeya sets in Rn , and σn > 0. Let K be a sticky Kakeya set with dimension n − σn + ε for
some small ε > 0 (we will call this an ε-extremal sticky Kakeya set), and let E be the discretization
of K at a small scale δ > 0. Then E contains a union of 1 × δ-tubes, which are sticky in the sense
of Katz, Laba, and Tao. Furthermore, this collection of δ-tubes is coarsely self-similar: for each
intermediate scale ρ ∈ (δ, 1), the ρ-thickening of K again resembles an ε-extremal sticky Kakeya
set, and the union of δ-tubes inside each ρ-tube resembles a (anisotropically re-scaled) ε-extremal
sticky Kakeya set. The precise statement is given by Proposition 3.2.
    In Section 4 we restrict attention to the case n = 3 and again follow arguments proposed by
Katz and Tao in [43]. We show that extremal sticky Kakeya sets must have a structural property

called planiness. Specifically, with K and E as above, if T is the set of 1 × δ tubes contained in
E, then there is a function V : E → S 2 so that for each point x ∈ E, the tubes in T containing
x must make small angle with the subspace V (x)⊥ . V (x) is called a plane map, and we use the
multi-scale self-similarity of extremal Kakeya sets to show that V must be Lipschitz. An important
consequence is that inside each ball of radius δ 1/2 , the set E can be decomposed into a disjoint
union of parallel rectangular prisms of dimensions roughly δ 1/2 × δ 1/2 × δ; these rectangular prisms
are called grains. After an anisotropic re-scaling, we obtain a new collection of 1 × δ tubes whose
union E ′ ⊂ R3 satisfies the following Property (P): For each z0 ∈ [0, 1], the slice E ′ ∩ {z = z0 } is
a union of parallel 1 × δ rectangles whose spacing forms an Ahlfors-regular set of dimension 1 − σ3 ;
the direction of these rectangles is determined by a “slope function” f (z0 ), which is Lipschitz. All
of the arguments described thus far also apply to the Heisenberg group example.
Step 2: Regularity of the slope function
In Section 5, we show that the slope function f (z) described above is C 2 (or more precisely, it
agrees at scale δ with a function that has controlled C 2 norm). To do this, it suffices to show that
at every scale ρ ∈ (δ, 1) and for every interval I of length ρ1/2 , the graph of f above ρ can be
contained in the ρ-neighborhood of a line. We will briefly describe how this is done. Fix a scale ρ
and an interval I, and let F ⊂ [0, 1]2 be a re-scaled copy of the graph of f above I. We will also
construct a set G ⊂ [0, 1]2 , which is the graph of a Lipschitz function g : [0, 1] → R that encodes a
local analogue of the plane map V . We construct the set G so that certain closed paths inside E ′
are encoded by arithmetic operations on the sets F and G. Specifically, whenever we select points
p ∈ F and q, q ′ ∈ G, we have that p·(q −q ′ ) specifies the location of one of the 1×δ rectangles in the
set E ′ ∩ {z = z0 } that was described above in Property (P). Since the spacing of these rectangles
form an Ahlfors-regular set, we conclude that

             F · (G − G)    is contained in an Ahlfors regular set of dimension 1 − σ3 .           (1.3)

    Recall that F and G are the graphs of Lipschitz functions, and thus satisfy a non-concentration
condition analogous to having Hausdorff dimension 1. Is it possible for (1.3) to occur? If F and G
are contained in orthogonal lines, then F · (G − G) is a point, so the answer is yes. The next result
says that this is the only way that (1.3) can occur.
Theorem 5.2, informal version. Let F and G be one-dimensional sets that have been discretized
at a small scale ρ > 0. Then either (A): (most of ) F and G are contained in the ρ-neighborhoods of
orthogonal lines, or (B): there exists some scale ρ ≤ t << 1 so that the t-neighborhood of F · (G − G)
contains an interval.
      The precise version of Theorem 5.2 is stated in Section 5 and proved in Section 8. Our proof
of Theorem 5.2 uses recent ideas from projection theory that were developed in the context of
the Falconer distance problem [33, 41, 36]. Specifically, the projection theorem we use generalizes
Bourgain’s discretized sum-product estimates; see [35, 38] for further recent developments in this
area. It is at this step where we distinguish between a sticky Kakeya set (which is a subset of
R3 ) and the Heisenberg group example (which is a subset of C3 ). In brief, if G is not contained
in a line, then by an analogue of Beck’s theorem due to Orponen, Shmerkin, and the first author
[36], we might expect G to span a two-dimensional set of lines, and hence a one-dimensional set
of directions, i.e. there is a one-dimensional set Θ ⊂ S 1 so that for each θ ∈ Θ, there are points
                     q−q ′

a direction θ ∈ Θ for which F · θ (and hence F · (q − q ′ ) ) has dimension 1. The actual proof of
Theorem 5.2 must overcome several difficulties when executing the above strategy. First, Theorem
5.2 has weaker hypotheses than the ones stated above; the set G · (F − F ) is replaced by a smaller

set, where the differences and dot products are taken along a sparse (but not too sparse!) subset
of F × G × G. Second, the proof sketch above supposes a dichotomy, where either G is contained

dichotomy is less apparent because G can behave differently at different scales.
    Returning to the proof of Theorem 1.1, if Item (B) from Theorem 5.2 holds, then by an obser-
vation of Dyatlov and the second author [12, Proposition 6.13], F · (G − G) cannot be contained
in an Ahlfors-regular set of dimension strictly smaller than 1. Thus Theorem 5.2 implies that the
graph of f above I must be contained in the ρ neighborhood of a line. Since this holds for every
interval I at every scale ρ, we conclude that f is C 2 . Kakeya sets with regularity conditions have
been studied in the past [18, 26], but different ideas are needed in this setting.
Step 3: Twisted projections
In Section 6 we exploit the fact that lines in a Kakeya set point in different directions to show that
the slope function f has (moderately) large derivative, i.e. |f ′ | is bounded away from 0.
    In Section 7, we begin by observing the following consequence of Property (P) from Step 1
above. Since each slice E ′ ∩ {z = z0 } is a union of parallel 1 × δ rectangles whose spacing forms    
an Ahlfors regular set and whose slope is given by f (z0 ), if we define πf (x, y, z) = x + yf (z), z ,
then πf (E ′ ) ⊂ [0, 1]2 has measure roughly δ σ3 . This is because each slice πf (E ′ ) ∩ {z = z0 } is a
union of δ-intervals that are arranged like a 1 − σ3 dimensional Ahlfors regular set.
    If T is a 1 × δ tube, then πf (T ) is the δ-neighborhood of a C 2 curve. Since the tubes in T
point in different directions and since |f ′ | is bounded away from 0, the corresponding curves πf (T )
satisfy a separation property related to Sogge’s cinematic curvature condition [31, 42]. The next
result says that the union of these curves must be large

Proposition 7.1, informal version. Let T be a set of 1×δ tubes pointing in δ-separated directions,
with #T ≳ δ −2S. Let f : [0, 1] → R with ∥f ∥C 2 ≲ 1 and |f ′ | ∼ 1. Then for all ε > 0, there exists
cε > 0 so that T ∈T πf (T ) has measure at least cε δ ε .

    The precise version of Proposition 7.1 is a maximal function estimate analogous to (1.1). It
is proved using a variant of Wolff’s L3 bound for the Wolff circular maximal function [47], where
circles are replaced by a family of C 2 curves that satisfy Sogge’s cinematic curvature condition.
This latter result was recently proved by Pramanik, Yang, and the second author [37]. Since E ′
contains about δ −2 tubes that point in δ-separated directions, Proposition 7.1 says that πf (E ′ )
must have measure at least cε δ ε , for each ε > 0. On the other hand, Property (P) says that πf (E ′ )
has measure at most δ σ3 . We conclude that σ3 = 0, which finishes the proof.

1.2   The sticky Kakeya conjecture versus the Kakeya conjecture
In this section, we will informally discuss what Theorem 1.1 tells us about the Kakeya conjecture.
In particular, how close does Theorem 1.1 get us to proving the Kakeya conjecture in R3 ? Katz and
Tao’s arguments from [43] begin by conjecturing that a (hypothetical) counter-example K ⊂ R3
to the Kakeya conjecture in R3 must have the structural properties stickiness, planiness, and
graininess. The results from [1] and [22] show that such a counter-example must be plainy and
grainy, but it is unclear whether K must be sticky. To reformulate the remaining part of Katz and
Tao’s conjecture in our language, we need the following definition.
Definition 1.2. A Kakeya set K ⊂ Rn is ε-close to being a sticky if there is a set of lines L with
packing dimension at most n − 1 + ε that contains at least one line in each direction, so that ℓ ∩ K
contains a unit interval for each ℓ ∈ L.



                                                   5
    In particular, a sticky Kakeya set is ε-close to being sticky for every ε > 0. The following
version of Katz and Tao’s conjecture says that Kakeya sets that are nearly extremal are close to
being sticky.
Conjecture 1.2. Suppose the Kakeya conjecture in Rn is false, i.e. inf dimH K = d < n, where
the infimum is taken over all Kakeya sets in Rn . Then for all ε > 0, there exists η > 0 so that the
following holds. Let K ⊂ Rn be a Kakeya set with dimH (K) ≤ d + η. Then K is ε-close to being
sticky.
   If Conjecture 1.2 is true for n = 3, then the following generalization of Theorem 1.1 would
imply the Kakeya conjecture in R3 .
Theorem 1.1′ . For all ε > 0, there exists η > 0 so that the following holds. Let K ⊂ R3 be a
Kakeya set that is η-close to being sticky. Then dimH K ≥ 3 − ε.
Remark 1.1. A consequence of Theorem 1.1′ is that if an X-ray estimate holds in R3 at dimension
d < 3, then there exists c > 0 so that every Kakeya set in R3 must have upper Minkowski dimension
at least d + c.
    One piece of evidence in favor of Conjecture 1.2 at the time it was formulated in [43] was that
the only known example of a Kakeya-like object with Hausdorff dimension less than 3 was the
(second) Heisenberg group example (1.2). As noted above, H is a counter-example to a strong form
of the Kakeya conjecture, and it has (complex analogues of) the structural properties stickiness,
planiness, and graininess.
    More recently, however, Katz and the second author [29] discovered a second Kakeya-like object
that has small volume at certain scales—this is analogous to having Hausdorff dimension less
than 3. This object is called the SL2 example, and it is not sticky. The SL2 example is not a
counter-example to Conjecture 1.2 (nor to the Kakeya conjecture) because it is not a Kakeya set
in R3 . Nonetheless, the existence of the SL2 example suggests that in order to resolve the Kakeya
conjecture in R3 , it will be necessary to study Kakeya sets that are far from sticky.
    As a starting point for this latter program, it seems reasonable to show that that the SL2
example cannot be realized in R3 . To make this statement precise, define LSL2 to be the set
of lines in R3 that can either be written in the form (a, b, 0) + R(c, d, 1) with ad − bc = 1, or
(0, 0, 0) + R(c, d, 0). Equivalently, LSL2 is the set of horizontal lines in the first Heisenberg group.
    We conjecture that lines from this set cannot be used to construct a counter-example to the
Kakeya conjecture.
Conjecture 1.3. Let K ⊂ R3 be compact, and suppose there is a set of lines L ⊂ LSL2 that
contains at least one line in each direction, so that ℓ ∩ K contains a unit interval for each ℓ ∈ L.
Then K has Hausdorff and Minkowski dimension 3.
Added November 3, 2022: Fässler and Orponen [16] have recently proved Conjecture 1.3.
    We will not discuss Conjectures 1.2 or 1.3 further. The remainder of this paper will be devoted
to proving Theorem 1.1 and 1.1′ .

lines in Rn of the form (p, 0)+Rv, where p ∈ [− n1 , n1 ]n−1 and v ∈ S n−1 has final coordinate vn ≥ 1/2.

from Section 1. We define the measure λn on Ln to be the product measure of (n − 1)-dimensional

these definitions of distance and measure, the packing dimension of a set L ⊂ Ln agrees with its

4    Planiness and graininess
For the remainder of the paper we will specialize to the case n = 3, and we will define σ = σ3 . Our
goal is to prove that σ = 0. In this section we will establish the existence of extremal collections of
tubes (T, Y )δ with additional structural properties. The first of these is the existence of a Lipschitz
plane map.
Definition 4.1. Let (T, Y )δ be a set of δ-tubes. A plane map for (T, Y )δ is a function V : ET → S 2

                            | dir(T ) · V (p)| ≤ δ for all p ∈ ET , T ∈ T(p).
    Next, we will show that each {z = z0 } slice of the Kakeya set is contained in a union of long
thin rectangles, which we will call global grains. These global grains will be arranged like an
Ahlfors-David regular set. The specific property we need is the following.
Definition 4.2. For n ≥ 1, α ∈ (0, n], C ≥ 1 and δ > 0, We say a set E ⊂ Rn is a (δ, α, C)n -ADset
if for all x ∈ Rn , all ρ ≥ δ, and all r ≥ ρ, we have
                                        Eρ (E ∩ B(x, r)) ≤ C(r/ρ)α .                                     (4.1)
Remark 4.1. Note that if E is a (δ, α, C)n -ADset, then so is every subset of E. This observation
will be used frequently in the arguments that follow. Definition 4.2 only imposes upper bounds
on the size of Eρ (E ∩ B(x, r)), while Ahlfors regularity usually requires a matching lower bound.
However, if E is a (δ, α, C)n -ADset that has bounded diameter and Eδ (E) has size roughly δ −α ,
then a large subset of E will satisfy a lower bound analogue of (4.1).

4.3    Grains
In this section, we will show that if an extremal set of tubes has a Lipschitz plane map, then
after restricting to a sub-collection, the tubes arrange themselves into parallel slabs, which are
called grains. In what follows, V will be a plane map for a collection of tubes. If Q is a cube
with center p, we define V (Q) = V (pQ ) (this is a unit vector in R3 ), and we define the projection
