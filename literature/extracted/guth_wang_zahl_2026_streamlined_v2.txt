                                                                     1. Introduction to the Kakeya problem
                                              A Besicovitch set is a compact set K ⊂ Rn that contains a unit line segment pointing in every
                                           direction. The Kakeya set conjecture asserts that every Besicovitch set in Rn has Minkowski and
                                           Hausdorff dimension n. We refer the reader to [6] and the references therein for an introduction
                                           to the Kakeya conjecture and its connections to problems in harmonic analysis.
                                              The Kakeya set conjecture was proved in dimension two by Davies [1], and was recently proved
                                           in dimension three by the second and third authors in a sequence of papers [8, 9, 10]. The purpose
                                           of this paper is to present a new, streamlined proof of the main result from the third paper [10].
                                              The first paper, [8], proves an important special case of this conjecture called the sticky Kakeya
                                           conjecture. The sticky case was formulated by Katz and Tao, who also outlined an approach to
                                           proving it, cf. [7]. The paper [8] proves the sticky case of the Kakeya conjecture, approximately
                                           following the outline from [7] but dealing with significant technical issues. The second paper
                                           [9] obtains a mild generalization of the sticky Kakeya theorem, and uses it to prove that every
                                           Besicovitch set in R3 has Assouad dimension 3; this is a weak form of the Kakeya set conjecture.
                                           The third paper, [10], reduces the general case of the Kakeya conjecture in R3 to the sticky case
                                           that was proved in [8, 9]. In this paper, we present a streamlined version of this reduction.

Remark 1.2. The original Kakeya conjecture concerns direction-separated tubes. One version
says that if T is a set of δ −(n−1) δ-tubes in Rn with δ-separated directions, then |U (T)| ⪆ 1. It is
straightforward to check that if the tubes of T are direction separated, then ∆max (T) ≲ 1, and so
Theorem 1.1 implies a similar estimate for direction separated tubes in R3 . The volume bound
(6) thus implies that every Besicovitch set in R3 has Minkowski and Hausdorff dimension 3.
   The goal of this paper is to give a detailed proof of Theorem 1.1. A key ingredient is the
sticky Kakeya theorem from [8, 9]. We give a self-contained proof that Theorem 1.1 follows from
the sticky Kakeya theorem. Our proof of Theorem 1.1 has the same main ideas as the one in
[10], but it has been reorganized to make it more concise. A couple parts of the argument in
[10], such as polynomial partitioning, are no longer needed.
   The introduction of [10] gives an overview of the main ideas of the proof. The expository
paper [4] gives an overview of the Kakeya problem, the sticky case, and the reduction to the
sticky case. The expository paper [5] gives a detailed outline of the reduction from the general
case to the sticky case. The current paper closely follows that outline.

2.3. Uniform sets of tubes. It will sometimes be useful to consider sets T that are uniform in
the following sense.
Definition 2.1. Let δ > 0, let M = ⌈log log 1/δ⌉, and let T be a set of δ-tubes in B1 ⊂ Rn . We
say that T is uniform if for each scale of the form ρ = δ k/M , k = 0, . . . , M , there is a set of
ρ-tubes Tρ so that
             S
     (i) T = Tρ T[Tρ ].
    (ii) The tubes Tρ are essentially distinct. Therefore each T ∈ T lies in Tρ for ∼ 1 choice of
         Tρ ∈ Tρ .
   (iii) |T[Tρ ]| is constant up to a factor ∼ 1 as Tρ varies in Tρ .
We call the numbers Nk = |T[Tρk ]| the branching numbers of T.
Definition 2.2. Let δ > 0, let M = ⌈log log 1/δ⌉, and let (T, Y ) be a set of δ-tubes in B1 ⊂ Rn
and their associated shading. We say that (T, Y ) is uniform if the following holds:
     • T is uniform.
     • For each point x ∈ U (T, Y ), the sets {T ∈ T : x ∈ Y (T )} are uniform, and have roughly
        the same branching numbers.
   The reason for setting M = log log(1/δ) in our above definitions is as follows. First, since
(log |T|)log log(1/δ) ⪅ 1, by pigeonholing, every set T of δ-tubes in B1 ⊂ Rn has a subset T′ of
cardinality |T′ | ⪆ |T| that is uniform, and every pair (T, Y ) has a ≈ 1-refinement that is uniform.
   Second, if T is uniform, then for every scale ρ ∈ [δ, 1], there is a set of essentially distinct
ρ-tubes Tρ that satisfies items (i) and (ii) from Definition 2.1, and satisfies the following slightly
weaker analogue of (iii): there is a number Nρ so that |T[Tρ ]| ≈ Nρ for all Tρ ∈ Tρ . Similarly for
Definition 2.2; the second bullet point is weakened to: the branching numbers Nk are roughly
the same up to a ≈ 1 factor.

V to the problem of understanding the Frostman sets VW for W ∈ W, and the problem of
understanding the Katz-Tao set W.

along the way we will see other sets of tubes and more generally other sets of convex sets. At
first sight, these other sets are not Katz-Tao or Frostman, but by using the maximal density
factoring we can reduce matters to Katz-Tao sets and Frostman sets, and we can study these by
induction.

                 7. Sticky Kakeya and a sticky / non-sticky dichotomy
   In this section we will discuss two variants of the sticky Kakeya theorem. Let T be a uniform
set of δ-tubes. Let ρ ∈ [δ, 1] and let Tρ be the thickening of T at scale ρ. We begin with the
following two observations
    (A) If T is Frostman, then by Remark 3.3(A), Tρ is Frostman. In general, however, the tubes
         in T[Tρ ] will not be Frostman inside Tρ .
    (B) If T is Katz-Tao, then by Remark 3.3(B), the tubes in T[Tρ ] will be Katz-Tao. In general,
         however, the tubes in Tρ will not be Katz-Tao.
   It will be helpful to consider the special cases where the sets T[Tρ ] are Frostman in Tρ , or the
set Tρ is Katz-Tao.
Definition 7.1. Let T be a set of δ-tubes in Rn .
(A) We say that T is Frostman at every scale with error C if for every scale δ ≤ ρ ≤ 1, we have

                              CF (T[Tρ ], Tρ ) ≤ C    for every Tρ ∈ Tρ .
(B) We say that T is Katz-Tao at every scale with error C if for every scale δ ≤ ρ ≤ 1, we have

                                           ∆max (Tρ ) ≤ C.
   We will usually consider sets of tubes that are uniform, in the sense of Definition 2.1, but this
is not required in the above definition.
Remark 7.2. Definition 7.1(A) is closely related to Definition 2.12 from [9]: if ϵ > 0 and δ > 0
is sufficiently small depending on ϵ, and if T is a uniform set of δ-tubes that is Frostman at every
scale with error δ −ϵ , then T “satisfies the Convex Wolff Axioms at every scale with error δ −ϵ ”
in the sense of [9], Definition 2.12.

scale. In that case, the sticky Kakeya theorem says that |U (T)| ⪆ 1 and µ(T) ⪅ 1. A mild
generalization of this result says that if T is Frostman at every scale then |U (T)| ⪆ 1, while if T
is Katz-Tao at every scale, then µ(T) ⪅ 1.
