Descriptive set theory concerns the study of “regular” or “tame” sub-
sets of separable complete metric spaces. We will begin by developing
a better understanding of which topological spaces admit separable,
complete metrics.
Deﬁnition 1. A topological space X is Polish if it is separable and
completely metrizable.
It is straightforward to characterize when a subspace of a complete
metric space is complete in the inherited metric.
Proposition 1. If (X, d) is a metric space and E ⊆ X, then E is
closed if and only if (E, d) is complete.
In particular, (0,∞), R\ Q, and Q all fail to be complete when given
the usual metric on R. The question of when a subspace of a Polish
space is Polish (as witnessed by a diﬀerent metric) is more subtle. For
instance any logarithm function is a homeomorphism between (0 ,∞)
and R. We will see momentarily that R\Q is also Polish while Q is not.
Speciﬁcally, Alexandroﬀ proved that the Polish subspaces of a Polish
space are exactly the subsets which are countable intersections of open
sets.

We begin by recalling the following classical metrization result from
point-set topology. This theorem gives a very useful criteria for deter-
mining when a topological space is metrizable.
Theorem 2. A regular topological space is second countable (i.e. has
a countable base of open sets) if and only if it is both separable and
metrizable.
The focus of this lecture is to prove embedding theorems for Polish
spaces. The ﬁrst theorem shows that any separable metric space can
be embedded into a compact metric space. Notice the separability
assumption is necessary since every compact metric space is separable
and every subspace of a separable metric space is separable.
Theorem 3. If X is a separable metric space, then X is embeddable
into [0, 1]N.
Proof. Let d be a complete metric on X which generates the topology
and which is bounded by 1. Let ( zn| n∈ N) enumerate a countable
dense subset of X and deﬁne a function φ : X→ RN by φ(x)(n) =
d(x, zn). We must show that φ is one-to-one, continuous, and that φ−1
is continuous.
To see that φ is one-to-one, suppose that x̸= y and let n be such
that d(x, zn) < d(x, y)/2. It follows that d(x, zn) < d(y, zn) and hence
that φ(x)̸= φ(y).
That φ is continuous follows from the fact that d is continuous. In
order to see that φ−1 is continuous, suppose that ( xm)m is a sequence
such that φ(xm)→ φ(x) for some x∈ X. Let ε > 0 be given and let
n be such that d(x, zn) < ε/3. Find an m0 such that if m > m 0, then
|d(xm, zn)− d(x, zn)| < ε/3. If m > m 0, then
d(xm, x)≤ d(xm, zn) + d(x, zn)
=|d(xm, xn)− d(x, zn) + d(x, zn)| + d(x, zn)
≤| d(xm, xn)− d(x, zn)| + 2d(x, zn) < ε.
Since ε > 0 was arbitrary, xm→ x. □
Corollary 1. If X is a compact metric space, then X is homeomorphic
to a closed subspace of [0, 1]N.
Proof. By the previous theorem, X is homeomorphic to a subspace of
[0, 1]N. Since X is compact, so is this subspace; since compact subspaces
are always closed, we are ﬁnished. □

Next we turn to the spaces 2 N ={0, 1}N and NN, which play a dual
role in understanding Polish spaces. If S is any set, deﬁne ∆ : SN→

The following theorems characterize the spaces 2 N and NN in terms
of their topological properties. Recall that a topological space is 0-
dimensional if it has a base of sets which are clopen (i.e. both closed

Theorem 5. 2N is homeomorphic to any compact metric space which
is 0-dimensional and has no isolated points.
Theorem 6. NN is homeomorphic to any Polish space which is 0-
dimensional and has no compact neighborhoods.
The space 2 N is commonly referred to as the Cantor set. It is home-
omorphic to the standard “middle third” Cantor set contained in the
unit interval. The space NN is commonly known as Baire space. By
the above characterization, it is homeomorphic to R\ Q.

Before going further, it will be useful to pause and deﬁne some ter-
minology and notation which will be used later. An ordinal is a set α
which has the following properties:
• (transitive set) if γ∈ β∈ α, then γ∈ α;
• (linearly ordered) if β̸= γ are in α, then β∈ γ or γ∈ β.
It can be readily checked that:
• the emptyset is an ordinal, which is usually denoted 0 when
viewed as such;
• if α is an ordinal, then so is α + 1 := α∪{ α} and if A is a set
of ordinals, then∪A is an ordinal.
Furthermore, we have the following key feature of ordinals.
Theorem 7. If α̸= β are ordinals, then α∈ β or β∈ α. Moreover,
every nonempty subset of the ordinals has an ∈-least element.
Thus we regard the class of all ordinals as being well ordered by ∈
(even though formally the class of all ordinals is a proper class and not
a set).
The ﬁnite ordinals naturally correspond to the nonnegative integers:
n :={0, . . . , n− 1}. The set of ﬁnite ordinals is denoted ω and we
will generally write ω instead of N from this point forward. Unless
otherwise stated, counting and indexing will start at 0 and the variables
i, j, k, l, m, n will range over ω.
A sequence is a function whose domain is an ordinal. The length of
a sequence s is deﬁned to be its domain and is denotes lh(s). In this
course, we will generally only work with sequences of length at most
ω. If S is a set, we will use S<ω to denote the set of all ﬁnite length

concatenation of s and t (the meaning should be clear enough when s

⟨a0, a1, . . . , an−1⟩ or⟨ai| i < n⟩ will be used to denote the sequence

Let X be a ﬁxed Polish space. The Borel subsets of X are the
members of the minimum collection Borel( X)⊆ P(X) such that:
• every open subset of X is in Borel( X);
• if B∈ Borel(X), then so is X\ B;
• ifB⊆ Borel(X) is countable, then ⋃B is in Borel( X).
Our ﬁrst goal will be to prove the following theorem.
Theorem 10. If X is a Polish space and B is a countable family of
Borel subsets of X, then there is a stronger Polish topology on X with
the same Borel subsets in which each element of B is clopen.
This follows from two lemmas which are of interest in their own right.
Recall that a regular open set is an open set which is the interior of its
closure. Notice that any separable metric space has a countable base
consisting of regular open sets.
Lemma 2. If X is a Polish space and U⊆ X is open, then the stronger
topology generated by declaring U to be clopen is Polish. Moreover, if
U is a regular open set and X has no isolated points, then the stronger
topology has no isolated points as well.
Proof. Deﬁne Y ⊆ X×{ 0, 1} by Y := U×{ 0}∪ (X\ U)×{ 1}. It is
readily checked that Y is a Gδ-subset of the Polish space X×{0, 1} and
hence Polish. Furthermore projection onto the ﬁrst coordinate deﬁnes
a continuous bijection π from Y to X. Moreover the restrictions of π
to U×{ 0} and (X\ U)×{ 1} are homeomorphisms onto U and X\ U.
In particular, π is a homeomorphism to the stronger topology on X
generated by declaring U to be clopen. Finally, if X has no isolated
points and U⊆ X is a regular open set, then neither U nor X\ U have
isolated points. Consequently Y has no isolated points. □

is a topological group in which the underlying topology is Polish. The
next remarkable theorem of Haar is very useful in producing examples

Theorem 29. If G is a locally compact group, then there is a Borel

• µ(K) <∞ if K⊆ G is compact;

If (X, E) and (Y, F ) are two Polish spaces equipped with equivalence

is an injection is an embedding. This provides a measure of relative
complexity of a equivalence relations on Polish spaces. Usually one
considers this ordering in the context of equivalence relations which
themselves have regularity properties – typically equivalence relations
of interest are at least analytic and often Borel.

We will now turn our attention to Gale-Stewart games and their de-
terminacy. Fix a set S and a subset Γ of Sω. In what follows, S will
be given the discrete topology and Sω will be given the product topol-
ogy. The Gale-Stewart Game associated to Γ is described as follows.
Players I and II alternately play a sequence of elements ⟨sk| k∈ ω⟩
of S: Player I starts by playing s0, Player II responds with s1, Player
I responds with s2, and so on. If the resulting sequence ⟨sk| k∈ ω⟩
is in Γ, then we declare Player I the winner; otherwise Player II wins.
At each stage of the game, both players have complete information as
to what has been played thus far, including the number of plays which
have already been made. Also, it is important to note that there is no
notion of a “draw” in which neither player wins or looses. The game
of chess could be coded as a Gale-Stewart game, provided we declared
black the winner whenever the game ended in a stalemate. Typically
the set S is countable, although it is often convenient to work with
some countable set other than ω. If Γ ⊆ Sω we will say that Γ is a
game played on S.
Typically we are interested in restriction on Γ which imply that it is
determined: i.e. one of the two players has a strategy which allows them
to always beat the other player, no matter how they play. Formally,
a strategy σ is a function from S<ω into S. Player I is said to follow
σ if s2k = σ(⟨si| i < 2k⟩ and similarly Player II is said to follow σ if
s2k+1 = σ(⟨si| i < 2k + 1⟩). Player I has a winning strategy if there is
a σ such that in every play in which Player I follows σ, Player I wins
(similarly one deﬁnes a winning strategy for Player II). We say that Γ
is determined if one of the two players has a winning strategy.
Notice that if S ={0, 1} and Γ ⊆ 2ω is such that neither Γ nor
2ω\ Γ contain a perfect subset, then the game associated to Γ is not
determined. Such a Γ can readily be constructed using the axiom of
choice. On the other hand, sets which are simply topologically, tend
to yield determined games.
