# R0001：条件 quadric 引理与高维 Hankel 障碍的独立审查

日期：2026-10-16（Asia/Shanghai）。审查者：独立子代理 `lifting_obstructions`。

结论：下述局部代数命题通过本轮逐步独立审查；仍未经外部同行评审。审查不覆盖整篇四维 Kakeya 证明、全部概率质量预算、近似误差或这些方向配置能否由一般 Kakeya 数据选出。本文不是高维 Kakeya 定理，也不是其反例。

## 1. 审查对象与张量约定

1. `notes/10_source_audit/四维证明维度障碍.md` 第 5.1 节的条件 quadric 替代引理，及其第 4.3 节 twisted-cubic 核计算的关键证明。
2. 主代理提出的 `d≥5` moment curve 上的三次 Hankel 行列式和五次乘积反例，及最终写入 `results/reviewed/ALG-001_moment_curve_obstructions.md` 的 A、B、C 三部分。

原稿 Lemma 6.6，印刷页 102–103，采用对称 r 线性型 T 与齐次多项式 `F(x)=T(x,…,x)` 的对应。因此

\[
D F(p)[u]=rT(p^{r-1},u),\qquad
D^2F(p)[u,w]=r(r-1)T(p^{r-2},u,w).
\]

特别地，三次 two-copy 检验等价于梯度为零，比例常数为 3；五次 three-copy 检验等价于 Hessian 为零，比例常数为 20。这里没有把标量求值与更强的梯度/Hessian 检验混用。

## 2. 条件 quadric 替代引理：通过

令 S_r 是 R^m 上齐 r 次多项式空间，`I_r(P)={F∈S_r:F(p_i)=0 对所有 i}`。精确假设是：

- p_i 张成 R^m；
- q 是非零实齐二次式，在 C 上不可约；
- `q(p_i)=0` 且 `∇q(p_i)≠0`；
- `I_3(P)=q S_1`。

这些是假设，尚未从高维 Kakeya 的线性方向丰富性推导出来。复不可约齐二次式必具有至少 3 的矩阵秩，因此有效情形自动满足 `m≥3`；不必额外声称 q 在全部 R^m 上非退化。

### 2.1 二次消失空间

若 `h∈I_2(P)`，每个 `x_jh∈I_3(P)=qS_1`，故 `q|x_jh`。不可约二次式 q 不可能整除非零一次式 x_j；多项式环是唯一分解整环，所以 `q|h`，继而 `h=cq`。反向包含来自 `q(p_i)=0`。因此

\[
I_2(P)=\mathbb Rq.
\]

这里整除论证不会把“在有限点集上为零”误当成全局整除；全局整除恰由显式输入 `I_3(P)=qS_1` 保证。

### 2.2 三次 two-copy 单射

设 `F∈S_3` 且 `∇F(p_i)=0`。每个 `∂_jF∈I_2(P)`，所以 `∂_jF=c_jq`。Euler 恒等式给出

\[
3F=\sum_jx_j\partial_jF=q\sum_jc_jx_j,
\qquad F=qL.
\]

在 p_i 上有

\[
0=\nabla F(p_i)=L(p_i)\nabla q(p_i).
\]

光滑性保证 `L(p_i)=0`；张成性保证 `L=0`，故 F=0。通过。

### 2.3 Three-copy 的 ranks 3、4、5

Rank 3 的核就是 `I_3(P)=qS_1`，直接来自假设。

Rank 4：若 `F∈S_4` 且 `∇F(p_i)=0`，则每个偏导在 `qS_1` 中。Euler 给出 `F=qH`，H 二次。选一个非零偏导 `∂_jq`，有

\[
q\mid\partial_jF=(\partial_jq)H+q\partial_jH.
\]

因 q 与非零一次式 `∂_jq` 互素，得 `q|H`，所以 `F=cq²`。反向包含由 `∇(q²)=2q∇q` 验证。

Rank 5：若 `F∈S_5` 且 `D²F(p_i)=0`，则每个四次式 `∂_jF` 属于刚证出的 rank-4 核，因此 `∂_jF=c_jq²`。Euler 给出 `F=q²L`，L 一次。再求导：

\[
\partial_jF=2q(\partial_jq)L+q²\partial_jL=c_jq².
\]

对一个非零 `∂_jq`，约去一个 q 后得到 `q|(∂_jq)L`，继而 `q|L`。次数迫使 L=0，故 F=0。通过。

### 2.4 点数与定量边界

`dim S_3=binom(m+2,3)`，乘以非零 q 在 S_1 上单射，所以 `dim(qS_1)=m`。若 N 个标量求值条件的核恰为 qS_1，必有

\[
N\ge\binom{m+2}{3}-m.
\]

因此 m=3 至少 7 点，m=4 至少 16 点，m=5 至少 30 点。原七点机制不能通过把 7 替换成 `2m+1` 自动保留。

精确核结论没有自动给出统一逆范数。若需要近似版本，必须控制有关求值/收缩矩阵的最小正奇异值、q 的归一化、光滑点梯度及方向张成的条件数，或另外证明一个包含全部所需下界的紧半代数族。审查只通过当前精确版本。

## 3. Twisted-cubic 核计算：关键步骤通过

审查配置为 `p(t)=(1,t,t²,t³)∈R⁴` 的 10 个互异实样点。任意四个方向的独立性来自 Vandermonde 行列式。

二次限制的像包含 `1,t,…,t⁶`，故核维数 `10−7=3`；三次限制的像包含 `1,t,…,t⁹`，故核维数 `20−10=10`。10 个样点足以使相应零限制成为全曲线零限制。

对 rank-4 核，写四线性型 T，并使用 `∇F(p(s))=0`。这意味着

\[
T(p(s),p(s),p(s),w)=0\quad\text{对所有 }w.
\]

沿 s 求导又有 `T(p(s),p(s),p'(s),w)=0`。所以

\[
c(s,t)=6T(p(s),p(s),p(t),p(t))
\]

对 t 在 t=s 处的 0、1、2、3 阶导均为零；关键的二阶项 `T(p,p,p',p')` 和三阶项 `T(p,p,p',p'')` 由后一个恒等式消掉。故 `(s−t)^4|c(s,t)` 的论证成立，而非仅依据 c 的对称性。

余因子是对称且分别次数不超过 2 的双变量式，空间维数为 6，可由

\[
1,\ s+t,\ st,\ (s+t)^2,\ (s+t)st,\ (st)^2
\]

作为一组基。三个二次生成元在割线上恰为

\[
(q_1,q_2,q_3)(a p(s)+b p(t))
=ab(s-t)^2(1,s+t,st).
\]

这给出六个 `q_iq_j` 的生成与独立性。割线参数映射的 Jacobian 为符号不计的 `ab(t−s)^4`，其像含实开集，故可由割线上的恒等式回到全空间多项式恒等式。

Rank 5 的 Hessian 在样点为零后，各三次偏导在整条曲线上为零；Euler 迫使函数和一阶导同样为零。割线两端各至少三重，五次式必须在割线上恒零，进而全零。三次 two-copy 同理使用割线两端各至少二重。

因此本配置的 three-copy ranks 3、4、5 核维数确为 `10,6,0`，三次 two-copy 仍单射。它在 ambient n=5 已反驳“二次核至多一维”的朴素推广，却没有反驳该配置下 two-copy 单射或 rank-5 核为零。

对 ALG-001.B 中的整数证书，另从 JSON 的行/列次序独立重建 40×35 系数矩阵，再计算指定 29×29 子式，得到行列式 `−104509440`，与记录一致。加上已独立证明的六个 `q_iq_j` 核向量及其线性独立性，可独立确认秩恰为 29。

## 4. d≥5 的 Hankel 构造：通过

这里用 d 表示 base 变量维数，与前节 m 同类；不是稿件密度亏损参数。令

\[
p(t)=(1,t,\ldots,t^{d-1})\in\mathbb R^d,\qquad d\ge5.
\]

选任意 N≥d 个互异实参数。任何 d 个方向的行列式为非零 Vandermonde 乘积，所以满足线性的 d 元 general position。

定义仅用前五坐标的三次式

\[
D(x)=\det\begin{pmatrix}
x_0&x_1&x_2\\
x_1&x_2&x_3\\
x_2&x_3&x_4
\end{pmatrix}
=x_0x_2x_4-x_0x_3^2-x_1^2x_4+2x_1x_2x_3-x_2^3.
\]

它非零，例如 `D(0,1,0,0,1)=−1`。代入 p(t)，Hankel 矩阵等于

\[
(1,t,t²)^T(1,t,t²),
\]

秩为 1。所有二阶余子式为零，因此行列式的各坐标偏导都为零；坐标重复造成的是若干余子式求和，不改变其为零。其余坐标的偏导恒零。于是

\[
D(p(t))=0,\qquad \nabla D(p(t))=0.
\]

非零三次式 D 对所有样点通过 two-copy 零检验，故该检验不再单射。由于恒等式对全部实 t 成立，增加有限样点数不能修复这一反例。

再令

\[
Q=x_0x_2-x_1²,\qquad F=DQ.
\]

Q 在 p(t) 上为零。F 为非零五次式，上述最终测试点满足 Q=−1，因此 F=1。乘积求导给出

\[
D²F
=Q D²D+D D²Q+\nabla D\otimes\nabla Q+\nabla Q\otimes\nabla D.
\]

在 p(t) 上，Q、D、∇D 全为零，故 Hessian 为零。于是存在非零 rank-5 对称张量，其 three-copy 检验在全部样点为零。通过。

本轮另用 SymPy 作独立精确展开核对，输出为：

```text
D = x0*x2*x4 - x0*x3**2 - x1**2*x4 + 2*x1*x2*x3 - x2**3
gradient D at p(t) = [0, 0, 0, 0, 0]
Hessian DQ at p(t) all zero = True
DQ nonzero = True
```

上文余子式和乘积公式才是证明；计算仅用于核查代数录入，且不需要浮点秩阈值。

**见证点修正核查。** 较早讨论中的 `(0,0,1,0,0)` 确使 D=−1，但同时 Q=0、F=0，因此只能见证 D 非零，不能见证 F=1。最终 ALG-001 已统一改用 `(0,1,0,0,1)`；本轮独立精确计算得到 `(D,Q,F)=(-1,-1,1)`，修正正确。额外坐标均补零。

## 5. 对总目标的准确含义

原模型保留一个隐藏标量时，base 维数等于 `ambient n−1`：原四维论文是 base 3；五维推广是 base 4；这里的 Hankel 构造要求 base 至少 5，对应 ambient 至少 6。

所以两类障碍必须分别登记：

- ambient n=5：twisted cubic 已破坏单一二次生成元假设，但其已核查的 two-copy 和 rank-5 检验仍有原来的零核性质；
- ambient n≥6：Hankel 构造同时破坏 three-degree two-copy 单射与 rank-5 three-copy 零核这两条朴素一般化。

这些有限维方向配置既不构成 Kakeya 集，也没有满足完整 native branch、质量预算、长轨道和多尺度条件。它们不能否定 Kakeya 猜想或完整的高维次数恢复命题；它们严格要求未来推广引入超出线性 general position 的代数信息。

局部 quadric 替代引理本身正确，但要接入总目标，下一项实质任务是从真实加权线族中证明相应三次求值核条件，或对多生成元/奇异三次核建立可编码的替代结构。仅再增加几个样点或重新命名方向丰富性不会排除本节恒等式反例。
