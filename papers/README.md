# 六维 Kakeya 17/4 论文

- 中文项目：`six_dimensional_17_over_4/main.tex`
- English project: `six_dimensional_17_over_4_en/main.tex`
- 两版都由 `main.tex`、`sections/` 和 `references.tex` 构成。下载时应保留整个项目目录；最终双语源码包会包含这两个完整目录。
- 中文使用 XeLaTeX、`ctexart` 和 Fandol 字体集；英文使用标准 `article`。英文也可使用 XeLaTeX。参考文献直接写在 `references.tex`，不需要 BibTeX。
- 在任一项目目录运行两遍 `xelatex -interaction=nonstopmode -halt-on-error main.tex`，或用 Codex 内置 LaTeX 编辑器打开该目录并编译。用户当前打开的中文版保持原位。

两版沿用相同的公式、标签和参考文献键。没有添加作者姓名或机构，没有提交至期刊或预印本平台。论文以明列四维有限尺度估计及 Katz–Tao 递推为输入；不把四维 Hausdorff 维数声明本身当作极大函数估计。文献比较冻结在2026-10-19已核范围，未经外部同行评审。
