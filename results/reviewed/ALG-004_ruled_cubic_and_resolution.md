# ALG-004：五维局部直纹三次模型与有限分辨率接口

日期：2026-10-16。轮次：R0002。状态：内部独立审查见 `research/reviews/R0002_coupling_adversarial.md`；未经外部同行评审，不声称新颖性。**本结果是对若干局部升维机制的限制，不是高维Kakeya反例，也没有改进一般维数下界。**

本轮比R0001增加的约束：反模型不再仅是孤立张量。它有非退化的二次主部、真实长仿射直线、原生二次测试和精确分支方程；新的二次测试在一块可观测base区域上不能同时小值且保持非零隐藏导数。不过模型尚未验证全部先验下界、原始尺度guards和临界路径条件，不能据此否定完整五维推广定理。

## 1. 精确模型

base坐标为 u=(u0,u1,u2,u3)∈R4，隐藏坐标为w。固定有界base盒U。设0<a<=S，ε=a/S，并取

q=u0*u3-u1*u2，k=u0*u2-u1²，r=u0*k，f=S q+a r。

q的对称矩阵行列式为1/16，非退化。定义原生二次测试及势函数

Ps(u,w)=P*(u,w)=w-S q(u)，P(u)=a r(u)。

则P*(u,f(u))=P(u)，且R=Ps(u,f(u))/a=r。分支f是整多项式，Ps,w=1，Ps,ww=0；R及其所有固定阶导在U上有固定常数界。以u=0为中心，f的二次Taylor主部正是S q，非仿射尺度S0与S可比（ε足小时，常数只依赖U）。

对θ∈[1,2]，置

Aθ(u)=u2-2θu1+θ²u0，
p(u,θ)=(1,θ,θ²,θ³-ε Aθ(u))。

精确恒等式为

D_p Aθ=0，k(p)=0，q(p)=-ε Aθ(u)，D_p²r(u)=2 Aθ(u)，r(p)=0。

这里D_p求导时将当前p视为固定方向，而不是对向量场反复微分。因p沿其自身积分线不变，两种定义在这些轨道上也一致。因此

f(u+τp)=f(u)+τ D_p f(u)

对所有实τ成立；其图面包含整条仿射直线。R=r沿该线为次数至多2的多项式。原测试沿实际见证线为二次，这不是从少数采样点拟合出来的。

对同一base点u，有p(u,θ)=M_u(1,θ,θ²,θ³)，其中M_u是行列式1的三角矩阵。所以任意四个不同θ的方向行列式等于原Vandermonde乘积。可在五个分离的参数区间中选方向，同时有量化一般位置。

当固定采样方向改为p0(θ)=(1,θ,θ²,θ³)时，D_p0³R=0，但D_p0²f=a D_p0²r，一般为O(a)而非O(a2)。若ε<=h，则a<=S h，故它满足原文(6.34)类型的弱误差a2+S0 h。由共同方向精度引入的S0项确实可以掩盖真实的三次扰动。

## 2. 任意二次测试的小值强迫隐藏导数退化

**命题。** 设U为固定base盒，F⊂U可测，归一化四维体积σ>0。对任意总次数<=2的多项式Q(u,w)，若

|Q(u,f(u))|<=E  （u∈F），

则

sup_U |Q_w(u,f(u))| <= C σ^(-24) E/a，
|Q_ww| <= C σ^(-24) E/S²。

常数只依赖U，不依赖a、S、Q。该结论不要求Q_w接近Ps,w。

**证明。** 唯一写成Q=A2(u)+(b+ℓ(u))w+c w²，其中A2总次数<=2、ℓ为齐一次式。T(u)=Q(u,Sq+ar)总次数<=6。固定次数多项式的可测集Remez估计及系数范数等价给出每个系数的绝对值<=Cσ^(-24)E。下面六个系数直接隔离b、ℓ和c，完全没有大系数抵消：

| T中的单项式 | 其系数 |
| --- | --- |
| u0²*u2 | a b |
| u0²*u3 | S ℓ0 |
| u0*u1*u3 | S ℓ1 |
| u0*u2*u3 | S ℓ2 |
| u0*u3² | S ℓ3 |
| u1²*u2² | c S² |

因此|b|<=Cσ^(-24)E/a，||ℓ||<=Cσ^(-24)E/S，|c|<=Cσ^(-24)E/S²。又||f||_U<=C S，且a<=S，所以Q_w=b+ℓ+2cf满足所述上界，Q_ww=2c同理。

所用Remez的指数24可自包含得到：一元次数<=6多项式在测度m的集合上选7个间距至少c m的点，用Lagrange公式得(C/m)^6的区间范数界。四维中按Fubini保留长度>=cσ的纤维，其base投影仍有测度>=cσ；逐坐标重复，每次多损σ^-6，至多σ^-24。固定U上的系数范数由固定插值网格控制。证明未使用浮点秩。

**带见证误差的推论。** 固定同一重截距组的中心c0，若每个u∈F有见证w(u)，满足|w(u)-f(u)-c0|<=a2，且某二次Q满足

|Q(u,w(u))|<=K a2，K^-1<=|Q_w(u,w(u))|<=K，|Q_ww|<=K/a2，

则当a2/a为固定幂小量、σ^-1和K均为subpower时，不可能成立。将w平移c0，再用精确二次Taylor公式，得到|Q(u,f(u))|<=C K a2。上面系数估计使图面上的隐藏导数至多Cσ^-24 K a2/a，且Q_ww本身被改进到Cσ^-24 K a2/S²。移回w(u)的导数误差因此也至多Cσ^-24 K a2²/S²，均小于K^-1，矛盾。

这里没有证明一个候选必须覆盖这样大的base集合或只能使用同一截距组；这些是接入整体Kakeya方案时必须另外核实的条件。

## 3. 有限网格联合cap不能自动排除超小ε

必须区分两种量词：

- 相对于同一固定moment参考palette π，在**全部任意细尺度**要求位置与方向联合乘积domination不能成立：足够细bin可能有π(J)=0而实际质量正。相对于真实全局velocity marginal的奇异相关性另见尺度审计；这里不否定正球状angular cap。
- 对**预先给定的有限个方向网格**，可以随后选足够小ε，删去很少的θ，使所有这些网格看到的方向bin只依赖θ，因而满足相应联合上界。

第二项的精确构造与审查见本轮局部模型笔记及尺度审计。其机制如下：初始u0=0，取y=(y1,y2,y3)与θ独立。沿线流动到时间τ后，空间坐标为

(y1+τθ，y2+τθ²，y3+τ[θ³-ε(y2-2θy1)])，

对y的Jacobian恰为1。若θ距所有预定网格的moment-curve bin边界均大于Cε，则对有界y和τ，实际可见速度V与(θ,θ²,θ³)始终处于同一bin。

有限网格在θ∈[1,2]上只有有限多个边界原像，各坐标导数均有正下界；删去的参数测度<=C_grid ε。因此可先给有限网格，再令ε足够小，使删失任意小且保留方向广度。C_grid依赖整个有限网格，不是无限尺度统一常数。

再取独立的d-Frostman截距测度μ_a，支持在宽度O(a)的集合上、总质量~a^d，满足μ_a(J)<=C|J|^d。设w=f(u)+c，X=Ps(u,w)=a r(u)+c。用上述Jacobian和截距cap积分，对每个已准备的速度binJ得到

λ(I、y盒B、X宽度w0、V∈J) <= C |I| |B| w0^d π(J)。

这展示(6.7)形式的有限网格**上界兼容性**。它没有验证(6.6)的全部参与系数箱下界、所有历史标签、原始分辨率排除或临界最优化。更细的ρ<<ε网格会重新看见V3与位置的线性约束，不能把本构造升级为一套对所有网格同时成立的极限模型。

## 4. 本轮结论与下一项真正缺口

原生二次耦合、长仿射见证、线性一般位置、主二次式非退化以及一份预定有限网格的联合上界，仍不足以单独证明五维次数恢复。关键的新接口是**分辨率网格与相对幅度S0/a的量词次序**：要求网格细到a/S0与允许事后取S0/a巨大，不是同一条件。S0本身可以趋于0，不能以其绝对有界替代比值控制。

下一轮应检查原始尺度guards和先验系数条件是否能提供统一的S0/a上界，或强制足以识别k(p)=0的低次多项式方向非集中。没有这类新输入，继续微调16方向插值或仅假设q非退化不会排除本模型。

本轮没有完整验证模型满足待推广Theorem6.1的全部假设；没有否定四维原稿，也没有给出一般五维Kakeya反例。
