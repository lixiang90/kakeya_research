# DIR-002：真实质量下界消去父数量与空间Jacobian

日期：2026-10-16，R0004。状态：内部独立复核通过，见research/reviews/R0004_direction_entropy_review.md；未经外部同行评审。初等概率与换元命题，不声称新颖性；未得到一般Kakeya维数下界改进。

## 1. 同一prior、同一层的精确命题

令可见空间维数为j≥2。world γ中的原始可见斜率V具有Lebesgue密度上界Cγ。trajectory prior为概率νγ，world权重为ωγ。每个时间块I内的完整trajectory assignments A互不相交，块长qA；同一系统满足ΣA ωγ(A) qA νγ(A)(A)≤1。

每个父的空间矩阵DA可逆，JA=|det DA|，真实饱和给

νA:=νγ(A)(A)≥Ksat^-1 nγ(b) JA。

在父单位坐标中V=vA+FA v′，FA=DA/qA。令EA′是这个父上固定的方向事件，限制在|v′|∞≤T，体积上界|EA′|≤ΦA。坐标、方向事件与矩阵不能依赖当前trajectory或当前时空点而改变。则

νγ(A)(A∩{v′∈EA′}) / νA
≤ min{1, Ksat Cγ ΦA/[nγ(b) qA^j]}。                         (D2.1)

证明：事件是原始V空间中vA+FA EA′的子集，故分子≤Cγ |det FA| ΦA=Cγ JA ΦA/qA^j；再使用饱和下界。JA恰好消去。完整assigned prior是分母，后续成功incidence质量不能替换它。

若当前incidence submeasure满足dλγ≤G dνγ dt，则全层bad质量满足

ΣA ωγ λγ(A×IA内bad)
≤G ΣA ωγ qA νA min{1,Ksat Cγ ΦA/[nγ(b)qA^j]}。          (D2.2)

若比率上界为统一β，右边≤G min(1,β)。比较当前总质量M中的比例时，仍需除M。world/time权重、被选择的层、固定测度与各处K因子必须一致。

这是比DIR-001逐父绝对体积界更强的实际层预算：不需要小父数或全局小palette，但仍需要控制可见方向密度与n(b)q^j之比。

## 2. 二次方向事件的两种阈值

对特殊抛物薄层|v′2−(v′1)^2|≤η，有Φ≤2η(2T)^(j−1)。这是线性η界，因为对v′2的一阶导恒1。

对一般系数归一化的次数≤2多项式Q(v′)，在固定有界方向盒上，DIR-001的初等sublevel证明只统一给Φ≤C sqrt(η)。若T=K且系数归一化/盒尺度有K损失，须另保留其固定幂。没有横向非退化输入时，不得把特殊抛物薄层的线性η界套到任意native Hessian二次式。

因此通用二次式版本的可检验排除量为

Ksat Cγ sqrt(η) / [nγ(b) q^j]，

而特殊抛物型有η/[nγ(b)q^j]。保留的质量须大于所有损失之后的bad上界，才有实际矛盾。

## 3. 实际分支不能免费继承整个父的floor

先固定每个父内的一支B及其方向多项式。若该分支incidence仅保证

λ(B×I)≥q νA f/Kbr，0<f≤1，

令βA为(D2.1)给出的prior比例上界，则λ(B内bad)/λ(B)≤min{1,G Kbr βA/f}。这里G只支付一次。不能把ν(B)直接当νA，也不能给ν(B)登记原父的n(b)JA饱和。同父有多个不同方向多项式时，必须另给事件并集的体积预算；若固定的一次构造仅有R≤K/f支，每支体积≤Φ，可用并集界支付K/f。不能对未受控数量的不同构造免费重复使用同一νA预算。

对原稿§6最终次数恢复，f=(a2/a)^d。固定一次potential P和packet Q之后，截距/core/sign等分组有这个质量损失；不同residual或不同potential产生的所有二次式不因此构成同一小全局palette。源码定位与完整限制见R0004_source_assignments.md。

## 4. 源稿中的适用边界

原稿Lemma2.10给νA∼log n(b)JA；Lemma2.13的真实父归一化使用ν(.|A)，V=vA+(DA/qA)V′。上述换元与预算直接适用于这些实际对象，原稿j=2，拟五维j=3须另验证相应结构约化。

父归一化后的可见斜率密度满足

Cnew≤Cγ JA/(qA^j νA)≤Ksat Cγ/[nγ(b)qA^j]。            (D2.3)

所以把新n(0)重置为1并没有消除成本；同一成本会进入新方向密度。原始full-slope density积分出可见密度时还要付原始隐藏斜率支撑长度，不能用已被缩放放大的隐藏坐标范围省略此项。

若额外有n(0)=N0^o(1)、Cγ=N0^o(1)、n(b)=N0^(-db+o(1))、q=N0^(-kb+o(1))，则特殊抛物事件预算为η N0^((d+jk)b+o(1))。固定原始η=N0^-c与b→0可相容地给衰减。一般二次式把c替为c/2。但Cor4.4只给相对profile及vanishing-depth节点，不给这些绝对密度与方向密度输入；不能直接得出排除。

更直接地，实际次数恢复在已选tangent父内通常只给η=Kh。即使乐观使用特殊线性η界，n≈a^d、q≈h、f=(a2/a)^d=h^(e d)时，含分支代价的预算尺度为

h^(1−e d)/(a^d h^j)。

当j≥2、0≤d<1、e>0时它不趋零；通用sqrt(η)更弱。这精确定位本轮公式不能直接完成次数恢复的阈值接口，而非仅因父数太多。

## 5. 宏观结论

新增了可用于真实饱和层的约束，但源数据当前未给出足够小的排除量。继续投入只重复原始/切线换底不会改变这一结论。本版本N5-POLY-CAP-01完成一次主轮后冻结；重新开启须有更强真实方向非集中、同一分辨率的全斜率似然控制，或不同的具体几何输入。
