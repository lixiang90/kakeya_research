# SCL-001：原始幅度界不能免费进入同一切线熵窗口

日期：2026-10-16，R0003。状态：范围/guard审计与算术蕴含通过内部复核，详见 `notes/40_multiscale/original_resolution/R0003_原始guards与幅度界.md` 及 `research/reviews/R0003_direction_budget_review.md`。未经外部同行评审。

本结果不证明真实优化临界路径上不存在更强的幅度界。它精确排除的是仅凭原始polynomial ranges、native复合导数界和现有窗口平均就免费细化速度网格的推理。

原定义的polynomial为N0^M，M在单个exact problem内固定，可随新问题改变。原生X及复合graph导数受控，不要求hidden w或分支f在切线单位内有统一固定幂界。具体分支norm比较目前只给

S0/a <= N0^[P(M_path)+ε_n s] = N^[P(M_path)/ε_n+s]，N=N0^ε_n。

这个上界本身不证明实际分支达到最坏增长。原始guards属于N0尺度，不是对S0/a的新切线统一界。

另一方面，原窗口选择要求U_n D_n ε_n→0、D_n→∞，且只控制速度网格不细于N^-U_n。若确有S0/a≈N0^m、m>0固定，而a2/a=N^-c，则分辨a2/S0至少要求

ε_n U_n >= m+c ε_n+o(1)。

这使U_n D_n ε_n >=(m+o(1))D_n→∞，直接违反同一窗口预算。原始base averaging mesh可以更细，不会自动给同样精细velocity标签的低互信息。

可复核数值序列为N0=2^(n^8)、ε_n=n^-3、N=2^(n^5)、S0/a=N0^m。它满足原始固定幂范围，却超过每个固定N^C。原始系数先验与native界相容的显式常密度半代数例子见审计笔记；该例没有证明positive horizon或临界最大化。

**修正上一轮的一处泛化措辞。** 在一般局部参数命题中，S0可趋零而S0/a仍增大；但在本研究固定场景a=N^-s中，如真有统一的绝对界S0<=N^C0（尤其S0<=常数），就已推出S0/a<=N^(C0+s)，足以为事前细化提供固定幂目标。当前缺的正是这样的切线统一控制，而不是说任何绝对上界都无用。原文可用的N0^M界不具有这个性质。

宏观决定：冻结仅靠现有guards和原窗口的修复路线。若后续从真实全方向质量或临界性得到新界，可以重启；不能把同一换底等式反复登记为新进展。
